# 品牌

[返回中文目录](../README.md)

- [绝对伏特加](absolut.md) — 瑞典伏特加品牌，现由保乐力加持有；以单一产地、冬小麦原料与连续蒸馏为卖点，透明瓶身、极简标签与长期艺术合作使其成为全球知名伏特加品牌之一。
- [白云边](baiyunbian.md) — 湖北松滋的兼香型白酒品牌，名称取自李白诗句；以“浓头酱尾”著称，产品分年份、年代、星级三条主线，十五年、二十年与三十年陈酿构成核心价格带。
- [张裕](changyu.md) — 烟台张裕葡萄酿酒股份有限公司的葡萄酒品牌；企业由张弼士于 1892 年创办，品牌产品覆盖解百纳、酒庄酒、冰酒与白兰地等系列。
- [芝华士](chivas-regal.md) — 苏格兰调和威士忌品牌，由保乐力加旗下的 Chivas Brothers 经营；以 12 年、18 年等年份标识与柔顺的调和风格著称，是高端调和威士忌的代表性名字之一。
- [稻花香](daohuaxiang.md) — 湖北宜昌的浓香型白酒品牌，隶属稻花香集团；名称取自辛弃疾词句，产品以清样为高端旗舰，活力家族覆盖宴席，珍品系列守传统渠道，手抄件系列尝试酱香风味。
- [董酒](dongjiu.md) — 贵州遵义董公寺的董香型（药香型）白酒品牌，由贵州董酒股份有限公司持有；以百草入曲、大小曲串蒸与双窖发酵为工艺特征，代表产品包括国密董酒与国密佰草香。
- [汾酒](fenjiu.md) — 山西杏花村汾酒集团体系内的清香型白酒品牌，下有青花、老白汾、玻汾等系列。本页讲品牌结构，不重复产品页的风味细节。
- [长城](greatwall.md) — 中粮集团旗下、由中粮长城酒业经营的国产葡萄酒品牌，产品以星级系列、酒庄酒与产区系列为主，覆盖日常餐酒到高端礼赠；具体产品的生产商与产区以瓶标为准。
- [健力士](guinness.md) — 源自爱尔兰都柏林的啤酒品牌，现由帝亚吉欧持有；以深色世涛、烘焙大麦风味与氮气泡沫口感著称，是世涛品类最具代表性的品牌之一。
- [古井贡酒](gujing-gongjiu.md) — 产自安徽亳州的浓香型白酒品牌，以“年份原浆”系列知名，产品覆盖多个酒精度。
- [轩尼诗](hennessy.md) — 法国干邑品牌，由路威酩轩旗下的酩悦轩尼诗经营；以 VS、VSOP、XO 等干邑等级与长期陈酿的调和原酒著称，是干邑产区最具代表性的品牌之一。
- [红星](hongxing.md) — 北京红星股份有限公司旗下的清香型白酒品牌，以二锅头“掐头去尾取中段”工艺为核心；蓝瓶绵柔系列与绿瓶传统系列构成日常主线，另有红星高照等礼赠与纪念产品。
- [黄鹤楼](huanghelou.md) — 武汉白酒品牌，由黄鹤楼酒业持有；以“南派大清香”为主线，同时经营陈香、生态原浆、楼系列与浓香型“更上层楼”，覆盖宴席、礼赠与次高端场景。
- [会稽山](huijishan.md) — 会稽山绍兴酒股份有限公司旗下的绍兴黄酒品牌，源自 1743 年东浦云集酒坊，以糯米、麦曲与鉴湖水酿造；产品覆盖五年陈、兰亭、水香国色等系列，属绍兴酒地理标志产品体系。
- [剑南春](jiannanchun.md) — 四川绵竹的浓香型白酒品牌，由四川剑南春（集团）有限责任公司持有；以多粮浓香和“天益老号”古窖池群为识别点，代表单品包括水晶剑南春、珍藏级剑南春与东方红1949。
- [酒鬼酒](jiuguijiu.md) — 酒鬼酒股份有限公司旗下的馥郁香型白酒品牌，产于湘西吉首；1987 年由黄永玉命名并设计麻袋瓶，代表产品包括内参、酒鬼与湘泉，以“一口三香”和多粮工艺为识别点。
- [尊尼获加](johnnie-walker.md) — 源自苏格兰的调和威士忌品牌，现由帝亚吉欧持有；以方瓶与红、黑、绿、金、蓝等颜色分级产品线著称，覆盖日常调饮到高端礼赠。
- [口子窖](kouzijiao.md) — 安徽淮北濉溪出产的兼香型白酒品牌，以“一步兼香”和多曲多粮工艺为识别点；产品覆盖口子窖年份系列、老口子、口子坊与口子酒，2015 年随安徽口子酒业股份有限公司上市。
- [郎酒](langjiu.md) — 四川古蔺二郎镇赤水河左岸的酱香型白酒品牌，由四川郎酒集团有限责任公司持有；主线包括青花郎、红运郎、红花郎与郎牌郎，另有郎牌特曲、顺品郎与小郎酒等兼香产品。
- [衡水老白干](laobaigan.md) — 河北衡水老白干酒业股份有限公司旗下的老白干香型白酒品牌；企业源于 1946 年组建的国营衡水制酒厂，2002 年上市。
- [泸州老窖](luzhou-laojiao.md) — 泸州老窖集团体系内的浓香型白酒品牌，核心产品包括国窖1573与泸州老窖特曲。品牌名与“1573”窖池年代相关，但名称不等于瓶中酒龄。
- [牛栏山](niulanshan.md) — 北京顺鑫农业股份有限公司牛栏山酒厂的白酒品牌，以二锅头工艺与大众价格带为核心，产品线覆盖清香型二锅头、浓香型牛栏山陈酿与百年牛栏山等系列。
- [舍得](shed.md) — 舍得酒业旗下的高端浓香型白酒品牌，2001 年 12 月推出；以“舍得”文化理念与老酒储备为定位，代表产品包括品味舍得、智慧舍得、藏品舍得与水晶舍得。
- [三得利](suntory.md) — 日本的饮料与酒类企业品牌，酒类业务涵盖日本威士忌、啤酒与烈酒；全球烈酒业务曾以 Beam Suntory（宾三得利）名义运营。
- [水井坊](swellfun.md) — 四川水井坊股份有限公司旗下的高端浓香型白酒品牌，2000 年推出；以水井街酒坊遗址为品牌基础，代表产品包括菁翠、典藏、井台与臻酿八号。
- [塔牌](taipai.md) — 浙江塔牌绍兴酒有限公司旗下的绍兴黄酒品牌，以手工冬酿、年份陈酿与出口系列构成产品线；品牌依托绍兴酒地理标志与非遗工艺叙事，覆盖日常自饮到礼赠的价格带。
- [青岛啤酒](tsingtao.md) — 源于 1903 年青岛的啤酒品牌，由青岛啤酒股份有限公司持有；主力产品为拉格啤酒，覆盖经典 1903、纯生、白啤与奥古特等系列。
- [五粮液](wuliangye.md) — 四川省宜宾五粮液集团有限公司旗下的浓香型白酒品牌，名称源于高粱、大米、糯米、小麦、玉米五种粮食。本页讲品牌结构，不重复产品页的风味细节。
- [西凤酒](xifeng.md) — 陕西凤翔的凤香型白酒品牌，由陕西西凤酒集团股份有限公司持有；产品线覆盖红西凤、珍藏版、酒海陈藏、老绿瓶、华山论剑与国花瓷等系列，价格从大众民酒延伸到高端礼赠。
- [习酒](xijiu.md) — 贵州习水的酱香型白酒品牌，由贵州习酒股份有限公司持有；厂区位于赤水河中游的二郎滩一带，代表产品包括君品习酒与习酒·窖藏1988。
- [洋河](yanghe.md) — 江苏洋河集团体系内的浓香型白酒品牌，以“绵柔”风格与蓝色经典系列知名，下有海之蓝、天之蓝、梦之蓝等产品线。
- [迎驾贡酒](yingjia-gongjiu.md) — 安徽霍山出产的浓香型白酒品牌，以“国人的迎宾酒”为公开口号，主打生态酿造与洞藏贮存；产品覆盖大师版、迎驾洞藏、金银星、百年迎驾与迎驾古坊等系列。
