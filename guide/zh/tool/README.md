# 器具

[返回中文目录](../README.md)

- [吧勺](bar-spoon.md) — 用于搅拌鸡尾酒、引导倾倒与量取少量液体的长柄吧台工具；长度、勺头容量与螺旋杆设计影响搅拌效率与操作手感。
- [啤酒开瓶器](bottle-opener.md) — 用于开启皇冠盖啤酒瓶的简易工具，常见酒吧刀、墙挂式与钥匙形；卡住瓶盖下缘，向上撬开，动作要稳。
- [刻槽刀](channel-knife.md) — 刀头带一个小 V 形或 U 形缺口的吧台刀，用来在柑橘皮上拉出细长均匀的皮条；缺口宽度、锋利度与下刀深度决定香气释放和装饰能否立住。
- [压榨器](citrus-press.md) — 通过杠杆或螺旋结构压榨半个柑橘的手动工具；杯口尺寸、稳定性与耐酸材料决定出汁效率、清洁难度与使用寿命。
- [鸡尾酒签](cocktail-pick.md) — 用来固定橄榄、樱桃、柑橘皮或洋葱等装饰的细签，常见长度 10–15 厘米；材质、长度、尖端处理与耐腐蚀性决定它能否稳住装饰又不干扰饮用。
- [摇酒壶](cocktail-shaker.md) — 用于摇和鸡尾酒的吧台工具，常见三段式与两段式两种结构；壶身、密封与滤冰方式影响冷却、稀释与操作效率。
- [开瓶器](corkscrew.md) — 用螺旋与杠杆拔出软木塞的工具，常见侍酒刀、蝶形与杠杆式；螺旋要居中，拔出要慢，断塞要处理。
- [细滤网](fine-strainer.md) — 双重过滤中的第二道滤器，用于拦下果肉纤维、碎叶与冰屑；网面精度、框架稳定性与清洁方式影响成品清澈度与速度。
- [比重计（hydrometer）](hydrometer.md) — 利用浮力读液体密度的玻璃仪器，常见密度、比重、酒精分与糖度刻度；必须配合温度修正，测的是密度而非直接酒精度。
- [冰桶](ice-bucket.md) — 用于给酒瓶降温的桶形容器，常为金属或玻璃；冰水混合比纯冰更快，水位要没过酒液，时间要看酒的类型。
- [量酒器](jigger.md) — 用于快速、重复量取少量液体的吧台量具；双头容量、刻度清晰度与倒口设计影响出品的稳定性与速度。
- [搅拌杯](mixing-glass.md) — 与吧勺配合、用于搅拌型鸡尾酒的杯具；杯壁厚度、容量与杯口形状影响搅拌效率、稀释速度与成品温度。
- [捣棒](muddler.md) — 在杯中轻压香草、水果与糖块的棒状工具；长度、头部形状与材质决定力度控制、清洁难度与杯具安全。
- [倒酒嘴](speed-pourer.md) — 装在烈酒瓶口的出酒嘴，用固定口径控制流速、让单手连续倒酒成为可能；它提高的是速度与一致性，精确计量仍要靠量酒器。
- [滤冰器](strainer.md) — 把冰块、碎冰与固体残渣拦在杯外的吧台工具；常见霍桑滤冰器与朱利普滤冰器，细网滤器用于二次过滤。
- [温度计](thermometer.md) — 测量酒液、酒瓶或酒窖温度的工具，常见探针式、红外式与贴片式；读数要稳定，校准要定期，测量位置要代表整体。
- [Y 形削皮器](y-peeler.md) — 手柄与刀片呈 Y 形或 T 形、双手操作的削皮器，可削出宽而薄的柑橘皮片或蔬菜皮；刀片是否可转、刃口间隙和下刀深度决定皮片厚度与带白瓤的多少。
