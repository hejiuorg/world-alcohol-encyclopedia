# 鸡尾酒

[返回中文目录](../README.md)

- [美国佬](americano.md) — 金巴利、甜味美思与苏打水调制的低酒精开胃酒，1860 年代起源于米兰；苦味、甜味与气泡的平衡，使它成为内格罗尼的前身。
- [阿佩罗气泡](aperol-spritz.md) — 以阿佩罗、普罗塞克与苏打水按经典三二一比例调制的低酒精开胃气泡酒，橙皮苦味、甜感与气泡构成主体。
- [飞行](aviation.md) — 1916 年由纽约 Hotel Wallick 的 Hugo Ensslin 记录于《Recipes for Mixed Drinks》，以金酒、Maraschino、柠檬汁与紫罗兰利口酒摇和，呈淡紫到灰蓝色，常以樱桃装饰。
- [蜂膝](bees-knees.md) — 禁酒令时期流行的金酒酸酒，以柠檬与蜂蜜糖浆替代砂糖，甜度与质地取决于蜂蜜糖浆的比例。
- [贝里尼](bellini.md) — 以普罗塞克与白桃泥调制的威尼斯经典，常引 1948 年 Harry's Bar 的 Giuseppe Cipriani 为起源；比例多为两份普罗塞克对一份桃泥，桃季与温度决定风味。
- [床笫之间](between-the-sheets.md) — 白朗姆、干邑、橙皮利口酒与柠檬汁摇和的经典鸡尾酒，口感介于侧车与玛格丽特之间；名字与巴黎酒吧文化有关，带有明显的暧昧意味。
- [血与沙](blood-and-sand.md) — 苏格兰威士忌、樱桃利口酒、甜味美思与橙汁等量摇和的经典鸡尾酒，颜色深红；名字来自 1922 年的斗牛电影，风味浓郁而平衡。
- [血腥玛丽](bloody-mary.md) — 以伏特加、番茄汁、柠檬汁、伍斯特酱、辣椒酱、盐与胡椒调制的长饮，芹菜与柠檬作装饰；起源常归于巴黎 Harry's New York Bar，具体人物与年份说法有争议。
- [花花公子](boulevardier.md) — 威士忌、金巴利与甜味美思调制的巴黎经典，1927 年首次见于书面配方，等份与 1.5:1:1 是两种主要比例。
- [白兰地亚历山大](brandy-alexander.md) — 白兰地、白可可利口酒与奶油等量摇和的甜点型鸡尾酒，表面撒肉豆蔻；名字与起源说法众多，是 20 世纪初美国酒吧文化的代表之一。
- [卡琵莉亚](caipirinha.md) — 以卡莎萨、青柠与糖捣压后加冰调制的巴西国饮，酸甜直接、酒体清爽；IBA 配方为 60 毫升卡莎萨、一个青柠与两茶匙糖，捣压与冰的用量决定成败。
- [香槟鸡尾酒](champagne-cocktail.md) — 糖块、安高天娜苦精与香槟构成的古典鸡尾酒，可选少量干邑；气泡从糖块上升，苦精的香料与香槟的酸度形成优雅对比。
- [三叶草俱乐部](clover-club.md) — 以金酒、柠檬汁、覆盆子糖浆与蛋清摇和调制的经典鸡尾酒，泡沫细腻、酸甜柔和，常见装饰为覆盆子；名字来自 20 世纪初美国的一家同名俱乐部。
- [还魂酒二号](corpse-reviver-2.md) — 以金酒、橙味利口酒、利莱白与柠檬汁等量摇制，并以苦艾酒洗杯的经典酸酒，茴香与柑橘是识别点。
- [大都会](cosmopolitan.md) — 以柠檬伏特加、君度、青柠汁与蔓越莓汁摇和后滤入杯中的经典鸡尾酒，酸甜清爽，颜色粉红，常见装饰为橙皮或青柠片。
- [代基里](daiquiri.md) — 白朗姆、青柠汁与细砂糖摇和而成的酸型经典。它结构极简，酸甜、稀释与温度任何一项失衡都会立刻暴露。
- [黑色风暴](dark-n-stormy.md) — 深色朗姆与姜汁啤酒加青柠调制的百慕大经典，Gosling's 持有商标；姜的辛辣与朗姆的焦糖形成强烈对比，做法简单却对姜啤品质敏感。
- [干马天尼](dry-martini.md) — 以金酒和干味美思调制的经典鸡尾酒，搅拌后滤入预冷的杯中，以柠檬皮或橄榄装饰。干度取决于味美思的比例，而不是名字。
- [浓缩咖啡马天尼](espresso-martini.md) — 以伏特加、咖啡利口酒、浓缩咖啡与糖浆大力摇和而成的现代经典，表面咖啡泡沫与香气是识别点。
- [法国 75](french-75.md) — 金酒、柠檬、糖与香槟构成的气泡短饮，常被追溯到一战期间巴黎的 Harry's New York Bar，名字来自法国 75 毫米野战炮。
- [吉姆雷特](gimlet.md) — 金酒与青柠糖浆（或鲜榨青柠汁加糖浆）调制的短饮，酸度、甜度与质地取决于用哪一种青柠。
- [金菲士](gin-fizz.md) — 金酒、柠檬汁、糖浆与苏打水组成的短饮；IBA 版为 45 ml 金酒、30 ml 柠檬汁、10 ml 糖浆，摇和后滤入细长杯、补少量苏打且不加冰；加蛋清即 Silver Fizz，加奶油与橙花水即 Ramos Gin Fizz。
- [蚱蜢](grasshopper.md) — 绿薄荷利口酒、白可可利口酒与奶油摇和而成的甜点型鸡尾酒，颜色淡绿、口感像薄荷巧克力；起源于新奥尔良的说法流传最广。
- [海明威代基里](hemingway-daiquiri.md) — 白朗姆、西柚、青柠与黑樱桃利口酒，不加糖，干、苦而酒精度高，常与哈瓦那 El Floridita 和“Papa Doble”联系在一起。
- [爱尔兰咖啡](irish-coffee.md) — 热咖啡、爱尔兰威士忌、红糖与轻微打发的奶油分层而成的热饮，1940 年代起源于爱尔兰福因斯机场；关键是温度、糖与奶油的浮层。
- [皇家基尔](kir-royale.md) — 黑加仑利口酒与香槟调制的法国经典，起源于第戎的基尔酒；颜色深红，气泡细密，甜酸对比强烈，是最简单的香槟鸡尾酒之一。
- [最后一语](last-word.md) — 金酒、绿查特、黑樱桃利口酒与青柠汁等份摇制，草本强度、樱桃核香与酸度并重，是 2000 年代现代经典复兴的代表。
- [长岛冰茶](long-island-iced-tea.md) — 五种基酒、柠檬汁、糖浆与可乐组成的高球鸡尾酒，看起来像冰茶，实际酒精度很高；1970 年代长岛酒吧的起源说法存在争议。
- [迈泰](mai-tai.md) — 1944 年由奥克兰的 Trader Vic 创制的提基经典；IBA 版以牙买加朗姆与马提尼克糖蜜朗姆各 30 ml，配橙皮利口酒、杏仁糖浆与青柠汁，加冰摇和后连冰倒入双份古典杯，以菠萝角、薄荷与青柠皮装饰。
- [曼哈顿](manhattan.md) — 以黑麦威士忌、甜味美思与苦精调制的经典鸡尾酒，搅拌后滤入杯中，以樱桃装饰。结构简洁，甜味与香料层层展开。
- [玛格丽特](margarita.md) — 以龙舌兰、橙皮酒和鲜榨青柠汁摇和而成的经典鸡尾酒。酸甜与盐边是结构的一部分，不是装饰口号。
- [马天尼兹](martinez.md) — 金酒、甜味美思、玛拉斯奇诺与橙味苦精调制的经典鸡尾酒，1880 年代出现于美国；被视为干马天尼与曼哈顿之间的桥梁，甜苦平衡微妙。
- [含羞草](mimosa.md) — 由等分香槟与橙汁调制的早午餐鸡尾酒，酒精度低、气泡轻盈；名字来自黄色花，配方简单却对温度与比例敏感。
- [薄荷朱利普](mint-julep.md) — 以波本威士忌、薄荷与糖调制的经典鸡尾酒，碎冰填满杯中，常见装饰为薄荷枝；风格清凉、甜润，是美国南方赛马文化的代表饮品。
- [莫吉托](mojito.md) — 以白朗姆、青柠、薄荷、蔗糖和苏打水调制的长饮。薄荷只轻压，冰要足，酸甜与气泡共同决定它是否清爽。
- [莫斯科骡子](moscow-mule.md) — 以伏特加、姜汁啤酒与青柠汁调制的长饮，姜的辛辣、气泡与青柠酸度构成主要平衡，常以铜杯或高球杯加冰饮用。
- [内格罗尼](negroni.md) — 由金酒、苦味开胃酒与甜味美思等量调制的经典鸡尾酒。鸡尾酒身份与配方版本分开记录。
- [古典](old-fashioned.md) — 以威士忌、糖、苦精与水调制的经典鸡尾酒。它用少量糖和水把烈酒打开，结构简单，却能清楚呈现威士忌本身。
- [老广场](old-pal.md) — 以黑麦威士忌、金巴利与干味美思等比例调制的经典鸡尾酒，搅拌后滤入杯中，常见装饰为柠檬皮，风格偏苦、偏干。
- [帕洛玛](paloma.md) — 以龙舌兰、西柚汁或西柚汽水与青柠调制的清爽长饮，西柚的苦甜、盐边与气泡构成主要特征。
- [纸飞机](paper-plane.md) — 以波本、阿佩罗、阿玛罗与柠檬汁等量摇制的现代经典，苦甜与柑橘平衡，呈粉橙色。
- [盘尼西林](penicillin.md) — 以苏格兰调和威士忌、柠檬、蜂蜜姜糖浆摇制，并浮一层艾雷岛威士忌的现代经典，烟熏与姜辣是识别点。
- [椰林飘香](pina-colada.md) — 白朗姆、椰浆与菠萝汁调制的热带鸡尾酒，1930 年代已有雏形，1954 年在波多黎各 Caribe Hilton 定型；可摇和或打碎，甜度与冰量决定成败。
- [粉红佳人](pink-lady.md) — 以金酒、applejack、柠檬汁、石榴糖浆与蛋白摇和的经典酸酒，粉色来自石榴糖浆，蛋白带来细腻泡沫；名字常与 1911 年百老汇音乐剧《The Pink Lady》联系在一起。
- [皮斯科酸](pisco-sour.md) — 以皮斯科、青柠汁、糖浆与蛋清摇制的酸类鸡尾酒，表面泡沫层与安高天娜苦精点缀是识别特征。
- [拉莫斯金菲士](ramos-gin-fizz.md) — 金酒、柑橘、奶油、蛋白与橙花水长时间摇和后加苏打的新奥尔良经典，泡沫丰厚如云；1888 年由 Henry C. Ramos 在梅耶餐厅定型。
- [萨泽拉克](sazerac.md) — 起源于美国新奥尔良的经典鸡尾酒，IBA 版以干邑、方糖与佩肖苦精调制，杯中以苦艾酒洗杯；黑麦威士忌版是美国内战后的替代传统。
- [边车](sidecar.md) — 以干邑、橙味利口酒与鲜榨柠檬汁摇和的经典酸酒，比例多为 50:20:20，糖边可选。
- [新加坡司令](singapore-sling.md) — 以金酒、樱桃利口酒、柑橘汁、菠萝汁与少量苦精摇和后滤入飓风杯的经典鸡尾酒；IBA 版本不加苏打水，以菠萝片与马拉斯奇诺樱桃装饰。
- [龙舌兰日出](tequila-sunrise.md) — 龙舌兰、橙汁与石榴糖浆在高球杯中形成的渐变鸡尾酒，颜色从橙黄过渡到红；1970 年代在加州走红，并因摇滚乐队巡演而广为人知。
- [汤姆柯林斯](tom-collins.md) — 老汤姆金酒、柠檬汁、糖浆与苏打水组成的长饮；IBA 将其列在 John Collins 条目下（45 ml 金酒、30 ml 柠檬汁、15 ml 糖浆、60 ml 苏打水），做 Tom Collins 时改用老汤姆金酒，柯林斯杯加冰，以柠檬片与樱桃装饰。
- [老广场](vieux-carre.md) — 黑麦威士忌、干邑、甜味美思、Bénédictine 与两种苦精调制的新奥尔良经典，双基酒与草本甜是识别点。
- [威士忌酸](whiskey-sour.md) — 以威士忌、柠檬汁与糖浆摇和后调制的经典鸡尾酒，酸甜平衡，表面可加蛋清泡沫；常见装饰为柠檬片或樱桃。
- [僵尸](zombie.md) — 1934 年 Donn Beach 在好莱坞创作的提基经典，以牙买加、波多黎各与德梅拉拉三种朗姆酒叠加 falernum、Donn's Mix 与石榴糖浆，酒精度高，常以薄荷枝装饰。
