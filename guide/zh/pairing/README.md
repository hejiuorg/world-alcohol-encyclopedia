# 搭配

[返回中文目录](../README.md)

- [奶酪配葡萄酒：按质地、咸度与脂肪搭](cheese-and-wine.md) — 奶酪的质地、咸度与脂肪决定配酒方向；从新鲜山羊奶酪到蓝纹奶酪，酸度、甜度与酒体比“红酒配奶酪”的成见更重要。
- [甜点配波特：比甜点更甜，才不腻](dessert-and-port.md) — 甜点与波特的搭配核心是“酒不能比甜点更不甜”；按甜点的甜度、脂肪与风味强度选 Ruby、Tawny 或 White Port，酸度与氧化风味决定收尾是否干净。
- [法餐配勃艮第：黑皮诺与酱汁的细腻对话](french-burgundy.md) — 法餐的黄油、蘑菇、禽肉与酱汁，与勃艮第红葡萄酒的轻酒体、高香与细单宁相合；搭配靠香气与酸度，而不是靠酒体压菜。
- [烧烤配啤酒：烟火气里的平衡](grilled-meat-beer.md) — 炭火的焦香、油脂与盐，遇上啤酒的气泡、苦味与低温；搭配的关键是选对类型、控制温度与节奏，而不是把啤酒当成解腻的水。
- [火锅配白酒：一口热，一口烈](hotpot-baijiu.md) — 火锅的油脂、辣度与高温，遇上白酒的高酒精度与香气；搭配的关键不是“越辣越要高度”，而是控制入口强度、温度与节奏。
- [意大利菜配桑娇维塞：番茄、橄榄油与酸度](italian-sangiovese.md) — 意大利菜的番茄、橄榄油、香草与硬质奶酪，与桑娇维塞的高酸、樱桃果香和干单宁相合；搭配靠的是酸度对齐，而不是单宁越重越好。
- [日料配清酒：鲜味与米香的平衡](japanese-sake.md) — 日料的生鲜、清淡与酱油鲜味，与清酒的米香、氨基酸鲜味和柔和酸度相合；按菜的油脂与酱汁浓淡，在纯米酒与吟酿之间选择。
- [江浙菜配绍兴黄酒：鲜与醇的同一套语言](jiangzhe-shaoxing.md) — 江浙菜的河鲜、酱汁与甜咸平衡，与绍兴黄酒的氨基酸鲜味、醇厚口感同源；搭配按菜的口感浓淡选择元红、加饭、善酿或香雪。
- [韩餐配烧酒：烤肉、泡菜与小杯节奏](korean-soju.md) — 韩餐的发酵辣味、烤肉油脂与共享式用餐，与稀释式烧酒的低度、微甜和小杯文化相合；搭配的关键是节奏、温度与菜序，而不是拼酒量。
- [墨西哥菜配啤酒：玉米、辣椒与青柠的清爽组合](mexican-food-and-beer.md) — 墨西哥菜的玉米、辣椒、青柠与油脂，和啤酒的气泡、苦度、麦芽甜味形成多层平衡；按菜的做法与辣度选拉格、IPA 或深色麦芽啤酒，比“冰啤酒配一切”更准确。
- [海鲜配香槟：气泡、酸度与咸鲜的三角](seafood-and-champagne.md) — 海鲜的鲜味、咸味与脂肪，与香槟的气泡、酸度和低单宁形成稳定三角；选对甜度、酒体与气泡强度，比“香槟只适合庆祝”的成见更重要。
- [鲁菜配酱香白酒：咸鲜浓味与空杯留香](shandong-sauce-aroma.md) — 鲁菜的咸鲜、葱香与浓稠酱汁，遇上酱香白酒的焦香、花果香与持久回味；搭配靠的是味觉厚度相当，而不是把菜做得更咸。
- [川菜配浓香白酒：麻辣与窖香的对抗](sichuan-strong-aroma.md) — 川菜的麻辣、油脂与发酵味，遇上浓香型白酒的窖香与粮香；搭配的关键是控制入口强度与节奏，而不是用高度酒去压辣。
- [西班牙菜配里奥哈：火腿、烤羊与橡木香](spanish-rioja.md) — 西班牙菜的火腿、橄榄、烤羊与海鲜饭，与里奥哈以丹魄为主的红葡萄酒相合；传统橡木桶带来的香草与香料，能承接咸鲜与油脂。
- [泰餐配雷司令：高酸与香气的解辣组合](thai-riesling.md) — 泰餐的酸辣、香茅、鱼露与椰奶，遇上雷司令的高酸与芳香；干型到半干型的选择取决于辣度、甜度与油脂，而不是“越甜越解辣”。点酒时看干型与半干型标注、酒精度与年份，侍酒温度通常控制在 8 至 10 摄氏度。
- [素食配葡萄酒：蔬菜、豆类与菌菇的搭配逻辑](vegetarian-and-wine.md) — 素食不是一种味道，而是一组差异很大的食材；按风味强度、酸度、苦味、鲜味与脂肪选酒，比“素菜配白葡萄酒”的成见更可靠。
