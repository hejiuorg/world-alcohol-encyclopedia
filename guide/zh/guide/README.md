# 指南

[返回中文目录](../README.md)

- [啤酒品鉴入门：从香气、酒体到苦度](beer-tasting-intro.md) — 从原料、发酵与风格三条线理解啤酒，说明第一杯怎么选、怎么倒与怎么喝、器具与温度、价格与购买，以及常见的品鉴误区。
- [换一只杯子，会有什么不同？](choose-a-glass.md) — 杯型改变香气聚集、入口位置与温度上升速度；先理解目的，再谈仪式。杯子不必昂贵，但要干净、合适、够用。
- [调酒，是另一种认识酒的方式](cocktail-basics.md) — 从基酒、酸甜、苦味、稀释和冰开始，理解一杯鸡尾酒的结构；先能稳定复现，再谈创作。
- [第一次喝白酒怎么选](first-baijiu.md) — 从场景、香型、度数、容量和预算出发，用一张决策表选出第一瓶白酒，并说明小杯慢饮、配餐与避坑要点。
- [第一口，先别急着下结论](first-tasting.md) — 从准备、观察、闻香到入口和余味，用自己的词记录一杯酒；先辨认偏好，再谈术语和评分。
- [第一次喝葡萄酒怎么选](first-wine.md) — 用场景、颜色、甜度、酒精度与预算五步选出第一瓶葡萄酒，说明标签核对、饮用温度、配餐与常见误区。
- [先看盘子里，再看杯子里](food-pairing.md) — 搭配不是寻找唯一答案，而是平衡浓度、酸度、甜度、脂肪与辛香；先尝一口，再决定下一口喝什么。
- [加冰这件事，没有标准答案](ice-and-temperature.md) — 冰会降温、稀释并改变香气释放；先决定你想保留什么，再决定加不加、加什么冰、加多少。
- [酒标很小，线索不少](read-a-label.md) — 酒标先告诉你类别、配料、酒精度和净含量；宣传语不等于事实，法规字段才是可核对的信息。
- [朗姆入门：从甘蔗到杯中](rum-intro.md) — 从原料、蒸馏、陈年与产区四条线理解朗姆的类型，说明第一瓶怎么选、纯饮与调酒怎么喝，以及价格、购买与常见误区。
- [清酒入门](sake-intro.md) — 从纯米、吟酿、大吟酿与本酿造的区别入手，解释精米步合、日本酒度、温度与喝法，帮第一次买清酒的人做选择。
- [龙舌兰与梅斯卡尔入门：两种龙舌兰酒的分野](tequila-mezcal-intro.md) — 从龙舌兰原料、产区与工艺解释特其拉与梅斯卡尔的区别，说明类型、第一瓶怎么选、怎么喝、价格与购买及常见误区。
- [威士忌入门](whisky-intro.md) — 从苏格兰单一麦芽与调和威士忌的区别入手，用一张决策表选第一瓶，并说明年份、酒精度、喝法与常见误区。
- [葡萄酒储存：温度、湿度、光线与震动](wine-storage.md) — 葡萄酒储存的核心是稳定：温度、湿度、光线、震动与空气都会改变酒的状态；从短期存放、开瓶后保存到长期陈放，按酒的类型与原计划分别处理。

状态不是 `reviewed` 的条目只用于迁移预览，不进入正式搜索。
- [白酒送礼 300–800 元怎么选](baijiu-gift-300-800.md) — 把 300–800 元白酒送礼拆成场景、香型、规格、包装与渠道五个判断：先确定收礼人喝不喝、几个人喝、要不要礼盒，再把预算分配到酒体而不是盒子；附常见坑与验真步骤。
- [黄酒送礼与自饮怎么选](huangjiu-gift-and-self.md) — 把黄酒的送礼与自饮分开：送礼看类型、年份、规格与包装，自饮看甜度、容量、开瓶后保存与配餐；先弄清干型、半干、半甜、甜型与加饭、花雕、香雪的关系，再决定买哪一瓶。
- [在餐厅怎么点葡萄酒](restaurant-wine-ordering.md) — 把餐厅点酒拆成预算、酒单结构、试酒、配餐与结账五步：先定一瓶酒的角色，再按杯或按瓶选择；不必背产区，只要会看酒单、会试温度、会拒绝坏酒。
- [单一麦芽还是调和威士忌](single-malt-vs-blend.md) — 把单一麦芽与调和威士忌放回定义、风味结构、价格与场景里比较：单一麦芽强调一家酒厂的个性，调和强调稳定与平衡；没有高下，只有你想要的体验与预算。
- [清酒酒藏参观怎么预约](sake-kura-visit.md) — 清酒酒藏参观不是随时能进的景点：先分清博物馆、酒藏见学与品鉴活动，再查预约、交通、语言与试饮安排；按“预约—到达—看什么—买什么—怎么回”的顺序准备，避免白跑。
- [精酿啤酒的新鲜度怎么看](craft-beer-freshness.md) — 精酿的新鲜度不是只看“生产日期”：还要看风格、酒花、包装、冷链与货架。按“日期—风格—储存—开瓶—品尝”的顺序判断，比背“三个月黄金期”更可靠。
- [酒礼盒避坑指南](liquor-gift-box.md) — 酒礼盒的坑集中在“盒子大、酒体小、来源不清、附赠品虚高”。按“酒体—规格—包装—来源—运输”五步检查，先把预算留给能喝的部分，再决定要不要为盒子付费。
- [低醇与无醇怎么选](low-alcohol.md) — 低醇、无醇、脱醇与“0.0”不是同一件事：先看标签上的酒精含量与工艺，再按场景、风味与安全选择；低醇不等于无醇，无醇也不等于可以无限饮用。
- [家庭酒柜怎么搭](home-wine-cabinet.md) — 家庭酒柜不是越贵越好，而是按“喝什么、几个人、多久喝完、放哪里”搭：先定用途与容量，再解决温度、湿度、避光与开瓶后管理；最后用一张清单控制品类与预算。
- [旅行带酒与托运怎么查](travel-bottle-check.md) — 带酒旅行先查承运人，再查海关，最后才是包装：随身与托运的液体规则不同，免税限量与申报义务也不同；玻璃瓶要防震、防漏、防压，别让一瓶酒毁掉整段行程。
- [中国白酒产区地图：从赤水河到黄淮](baijiu-regions-map.md) — 把中国白酒的主产区放回地理：赤水河、宜宾—泸州、绵竹—古蔺、习水、宿迁、汾阳、亳州各自的水、粮、气候与工艺，决定了香型与风格的差异；附 8 条产区路线的读图方法。
- [世界威士忌酒厂旅行怎么排](whisky-distillery-travel.md) — 把威士忌酒厂旅行按“产区—交通—预约—参观—品鉴—买酒”排：苏格兰岛屿与高地、日本山崎与余市、美国与爱尔兰各有节奏；先定一条主线，再排酒厂，不要用地图直线距离做行程。
- [葡萄酒产区旅行预算怎么定](wine-region-budget.md) — 把葡萄酒产区旅行拆成交通、住宿、品鉴费、餐饮、买酒与保险六块：先定产区与季节，再按“每天 2 家、留半天机动”排；预算要从总花费倒推，不要只算机票。
- [黄酒与江南餐桌](huangjiu-jiangnan-table.md) — 把黄酒放回江南餐桌：从绍兴、苏州、上海的家常菜与节气，解释干型、半干、半甜、甜型怎么配；再看温饮、杯型、酒馆与产区路线，形成一张“菜—酒—温度”的对照。
