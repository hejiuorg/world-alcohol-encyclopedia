# 工艺

[返回中文目录](../README.md)

- [调配](blending.md) — 把不同批次、年份、品种或桶型的酒液按比例组合，以稳定品质、平衡结构或形成固定风格的工序；葡萄酒、香槟、威士忌、白兰地与白酒的法规与调配逻辑各不相同。
- [蒸馏](distillation.md) — 利用乙醇与水等组分沸点不同，将发酵液或酒醅中的乙醇分离并浓缩的工序；设备、回流与切酒方式决定烈酒的风味走向。
- [发酵](fermentation.md) — 酵母或细菌在低氧条件下把糖转化为乙醇、二氧化碳与风味物质的代谢过程；菌种、温度、糖浓度、pH 与氧决定发酵速度、酒精度和香气走向。
- [加强（加度）](fortification.md) — 向葡萄酒中加入葡萄蒸馏酒以提高酒精度并稳定酒体的工序；发酵中途加度可保留残糖，发酵后加度则得到干型加强酒，加度时机与比例决定最终风格。
- [生酛与山废](kimoto-yamahai.md) — 清酒依靠天然乳酸菌培养酒母的两条传统路线；生酛保留山卸，山废省略山卸，二者都区别于直接添加乳酸的速酿酒母，并影响酸度、旨味与生产周期。
- [拉格低温贮酒](lagering.md) — 主发酵之后的低温贮酒工序：酵母回收双乙酰、悬浮物沉降、硫化物逸散并完成自然碳酸化；温度曲线、时间与溶氧共同决定拉格啤酒的干净度与保质期。
- [酒泥陈酿](lees-ageing.md) — 让葡萄酒与发酵后沉降的细酒泥保持接触的熟成方式；搅泥频率、温度与时间带来圆润口感、奶油与面包气息，并形成还原保护，但处理不当会产生硫化物与苦涩。
- [苹果酸-乳酸发酵](malolactic-fermentation.md) — 乳酸菌把苹果酸转化为乳酸与二氧化碳的二次发酵；它降低滴定酸度、提高 pH 并软化口感，适量产生奶油气息，失控则带来挥发酸、生物胺与酒体浑浊。
- [制麦](malting.md) — 把大麦等谷物浸泡、发芽、烘干并除根的预处理工序；发芽程度与烘干曲线决定淀粉酶活力、麦芽溶解度和色度，进而影响糖化效率与成品风味。
- [混蒸混烧](mixed-steaming.md) — 把新粮与酒醅同甑蒸煮并在同一次蒸馏中接酒的固态法白酒工序，与清蒸清烧相对；它通常与续糟配料配套，决定粮香、酒体饱满度与糟醅循环方式。
- [橡木桶陈酿](oak-ageing.md) — 将酒液贮存在橡木桶中，让木材、微量氧气与时间共同改变香气、单宁、颜色与质感的工序；桶种、尺寸、新旧与烘烤程度都是可调变量。
- [压榨](pressing.md) — 压榨是把葡萄汁或酒液从皮渣、种子与梗中分离出来的工序；白葡萄酒多在发酵前压榨，红葡萄酒多在浸渍或发酵后压榨，压力曲线与取酒分段决定产量、单宁与酒体。
- [制曲](qu-making.md) — 用谷物培养霉菌、酵母和细菌，制成糖化发酵剂的传统工序；曲的质量与微生物群落直接影响白酒、黄酒的出酒率与风味。
- [糖化](saccharification.md) — 把谷物等原料中的淀粉分解为可发酵糖的工序；麦芽酶、曲霉酶与温度、pH、料水比共同决定糖谱，并影响酒体、出酒率与发酵能否顺利收尾。
- [固态发酵](solid-state-fermentation.md) — 以含水率较低的固态粮醅为载体的发酵方式，是中国白酒固态法的基础；与半固态法、液态法相对，容器、曲种与温湿度管理决定风味走向。
- [堆积发酵](stacked-fermentation.md) — 把拌曲后的酒醅在入窖前堆放一段时间、借助自然升温扩大培养微生物的开放式工艺环节，常见于酱香型白酒。
