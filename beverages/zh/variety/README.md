# 品种

- [艾格尼科](aglianico.md) — 意大利南部（巴斯利卡塔与坎帕尼亚）的红葡萄，晚熟、色深、单宁与酸度都很高；图拉斯与 Vulture 火山土是它的两个标志性产区，酒需要陈年才能舒展。
- [阿尔巴利诺](albarino.md) — 西班牙西北部加利西亚的白葡萄，在葡萄牙称 Alvarinho；果皮较厚、酸度高，带柑橘、白花与海风般的咸鲜感，适合搭配海鲜。里亚斯·拜萨斯与绿酒产区的蒙桑-梅尔加苏是核心产地。
- [阿斯蒂科](assyrtiko.md) — 希腊圣托里尼的白葡萄，耐旱抗风，在火山土与海风中保持高酸；干白带柠檬、火石与海盐气息，Vinsanto 则是它的甜型分支。
- [巴贝拉](barbera.md) — 意大利皮埃蒙特的红葡萄品种，酸度高、单宁中等、颜色深，耐热且产量稳定；常与内比奥罗形成“高酸配高单宁”的对照。阿斯蒂巴贝拉于 2008 年升为 DOCG，规定至少 90% 巴贝拉。
- [蓝弗兰克](blaufrankisch.md) — 奥地利布尔根兰的红葡萄，也在匈牙利称 Kékfrankos、捷克称 Frankovka；带深色、黑樱桃、胡椒与香料，酸度高、单宁中高，陈年潜力好。
- [品丽珠](cabernet-franc.md) — 法国波尔多与卢瓦尔河谷的红葡萄品种，果皮较薄、成熟早于赤霞珠，单宁中等、香气外放，以覆盆子、紫罗兰、石墨与青椒气息著称；它是赤霞珠的亲本之一，在波尔多右岸与卢瓦尔河谷常用于单一品种或混酿。
- [赤霞珠](cabernet-sauvignon.md) — 重要的红葡萄品种，果粒小、皮厚、晚熟，单宁与色素潜力高；原产于波尔多，现广泛种植于世界主要葡萄酒产区。
- [佳丽酿](carignan.md) — 地中海西部的红葡萄，原产西班牙阿拉贡一带，在法国朗格多克、西班牙加泰罗尼亚与意大利撒丁岛广泛种植；老藤低产时酸度高、单宁强、带香料与泥土。
- [佳美娜](carmenere.md) — 原产法国波尔多的红色品种，19 世纪传入智利后长期被误认作梅洛；1994 年重新鉴定，成为智利标志性品种。晚熟、色深，带黑李子、黑莓与青椒气息，常经橡木陈年。
- [霞多丽](chardonnay.md) — 重要的白葡萄品种，香气中性、适应性强；从勃艮第干白到香槟起泡酒都有广泛使用，风格很大程度上由产区与酿造处理决定。
- [白诗南](chenin-blanc.md) — 原产于法国卢瓦尔河谷的白葡萄品种，果皮薄、酸度高、成熟较晚，易受贵腐菌侵染；可酿干白、半干、甜白与起泡酒，以榅桲、苹果、蜂蜜与洋甘菊香气著称。DNA 研究显示它是萨瓦涅与未知品种的杂交后代，在南非被称为 Steen。
- [神索](cinsault.md) — 法国南部的红葡萄，耐旱、产量高，酒色浅、单宁低、酸度中高；常用于桃红、混酿与南罗讷的“神索-歌海娜”组合，也在南非与黎巴嫩种植。
- [科维纳](corvina.md) — 意大利威尼托的红葡萄品种，果皮较薄、颜色中等，以酸樱桃、杏仁与草本香气著称；是瓦坡里切拉与阿玛罗尼的核心品种，常与科维诺内、罗迪内拉同组混酿。
- [多切托](dolcetto.md) — 意大利皮埃蒙特的红葡萄，名字意为“小甜”，但酒通常干型、单宁低、酸度中高，带黑樱桃、李子与杏仁；适合年轻时饮用，是巴罗洛与巴巴莱斯科的日常对照。
- [黑姑娘](feteasca-neagra.md) — 罗马尼亚与摩尔多瓦的原生红葡萄，名字意为“黑姑娘”；酒色深、单宁中高，带黑樱桃、李子、香料与泥土，常被比作黑皮诺与西拉的混合。
- [富尔民特](furmint.md) — 富尔民特是匈牙利托卡伊的核心白葡萄，酸度高、皮厚、易感染贵腐菌；既酿出以阿苏为代表的贵腐甜酒，也酿出日益重要的干型富尔民特，风格从蜂蜜杏脯到柑橘与烟熏。
- [佳美](gamay.md) — 皮薄、早熟、酸度高的红葡萄品种，是博若莱红葡萄酒的核心品种；以整串发酵与花岗岩土壤上的果味著称，风格从轻盈易饮到可陈年的村庄级 cru 都有。
- [加尔加内加](garganega.md) — 意大利威尼托索阿韦产区的白葡萄，晚熟、产量高，带柠檬、杏仁、白花与矿物；可酿干型 Soave、甜型 Recioto di Soave 与起泡酒。
- [琼瑶浆](gewurztraminer.md) — 果皮呈粉红色的芳香型白葡萄品种，名称源自意大利南蒂罗尔的特拉明（Tramin）；它是萨瓦宁（Savagnin）的芳香变异，酸度偏低、糖分积累快，以荔枝、玫瑰、姜与肉桂香气著称，主要种植于阿尔萨斯、德国、奥地利与意大利北部。
- [格莱拉](glera.md) — 意大利威尼托与弗留利的白葡萄品种，2009 年前品种名与酒名同称 Prosecco，后改用格莱拉以保护产区名称；果皮薄、酸度中等，以青苹果、梨与白花香气著称，是普罗塞克的核心品种，在尤加内山一带又称 Serprino。
- [格德约](godello.md) — 西班牙西北部 Valdeorras、Ribeiro 与 Monterrei 的白葡萄，带柑橘、白花、矿物与坚果，酸度中高、质地饱满；可酿清爽型或橡木桶型。
- [歌海娜](grenache.md) — 耐热、耐旱的红葡萄品种，果皮较薄、糖分积累快、酸度偏低；它在罗讷河谷混酿与西班牙 Priorat 等产区中承担果味与酒精度的支撑。DNA 研究确认西班牙的 Garnacha 与撒丁岛的 Cannonau 都是同一品种。
- [绿维特利纳](gruner-veltliner.md) — 奥地利的代表性白葡萄品种，晚熟、酸度高，典型香气为柑橘、青豌豆与白胡椒；DNA 研究显示它是特拉明与奥地利古老品种 St. Georgen 的自然杂交后代，在瓦豪按酒精度分为 Steinfeder、Federspiel 与 Smaragd 三级。
- [卡达卡](kadarka.md) — 匈牙利与巴尔干的红葡萄，酒色浅、酸度高、单宁低，带红樱桃、香料与胡椒；曾是匈牙利最重要的红葡萄，现为 Szekszárd 与 Eger 的传统品种。
- [马卡贝奥](macabeo.md) — 西班牙北部的白葡萄，在里奥哈称 Viura、在加泰罗尼亚称 Macabeo；酸度中等、带青苹果、白花与柑橘，是卡瓦与里奥哈白葡萄酒的基础。
- [马尔贝克](malbec.md) — 原产于法国西南部的红葡萄品种，果皮深色、单宁充沛，对霜冻与坐果不良敏感；在阿根廷门多萨的高海拔环境下成为标志性品种。
- [玛尔维萨](malvasia.md) — 地中海与伊比利亚的白色品种家族，包含多个克隆与变种；香气从白花、杏、蜂蜜到香料，可酿干白、甜酒与加强酒，不能当作单一品种。
- [玛珊](marsanne.md) — 北罗讷河谷的白葡萄，常与胡珊混酿；酒体饱满、酸度低、带蜂蜜、蜂蜡、坚果与白花，陈年后更显圆润，是埃米塔日白葡萄酒的主要品种。
- [勃艮第甜瓜](melon-de-bourgogne.md) — 白葡萄品种，原产法国勃艮第，现主要种植于卢瓦尔河谷南特一带，用于酿制密斯卡岱；与霞多丽同为 Gouais Blanc 与黑皮诺的后代，酸度高、香气中性，常经酒泥陈酿获得圆润质地。
- [门西亚](mencia.md) — 西班牙西北部 Bierzo 与 Ribeira Sacra 的红葡萄，带黑樱桃、草药、香料与矿物，酸度高、单宁中低；常被误认为品丽珠或佳美。
- [梅洛](merlot.md) — 波尔多右岸常见的红葡萄品种，果粒中等、皮较薄、成熟较早，单宁与酸度中等；它既能单独酿酒，也常与赤霞珠等品种混酿。
- [蒙特普尔恰诺](montepulciano.md) — 意大利阿布鲁佐的红葡萄，与托斯卡纳的蒙特普尔恰诺小镇无关；酒色深、单宁中低、酸度中高，带黑樱桃、李子与香料，是意大利南部最常见的红葡萄酒之一。
- [慕合怀特](mourvedre.md) — 原产于西班牙与地中海沿岸的晚熟红葡萄品种，皮厚、单宁强、耐热耐旱；在法国普罗旺斯与罗讷河谷常与歌海娜、西拉混酿。
- [米勒-图高](muller-thurgau.md) — 德国培育的白葡萄，由雷司令与马德雷尔（Madeleine Royale）杂交而来；早熟、产量高，带花香、柑橘与轻微麝香，是德国种植面积最大的白葡萄之一。
- [麝香](muscat.md) — 麝香是一个古老而庞大的葡萄家族，小粒麝香香气最浓，亚历山大麝香果粒更大；从阿尔萨斯干白、意大利莫斯卡托微起泡到法国与澳洲的加强甜酒，风格跨度极大，核心是浓郁的花香与葡萄香。
- [内比奥罗](nebbiolo.md) — 意大利皮埃蒙特的代表性红葡萄品种，晚熟、皮厚，颜色偏浅但酸度与单宁很高，带玫瑰、焦油与红樱桃气息；巴罗洛与巴巴莱斯科都以它为核心品种。
- [黑达沃拉](nero-d-avola.md) — 西西里最重要的红葡萄，颜色深、单宁中高，带黑莓、黑樱桃、李子与香料；在 Noto、Vittoria 与 Etna 周边表现不同，常与弗拉帕托混酿。
- [派斯](pais.md) — 智利的老藤红葡萄，源自西班牙的 Listán Negro/Gros Collet，在 Itata 与 Maule 的干旱老园中保留；酒色浅、酸度高、单宁低，带红樱桃、干草与香料。
- [帕洛米诺](palomino.md) — 西班牙安达卢西亚的白葡萄，雪莉的主要品种；本身风味中性、酸度低，风格几乎全部来自生物陈酿（flor）或氧化陈酿与索莱拉系统。
- [帕雷亚达](parellada.md) — 加泰罗尼亚佩内德斯的白葡萄，卡瓦三大品种之一；酸度高、酒体轻、带青苹果、柑橘与白花，常与沙雷洛、马卡贝奥混酿增加清爽感。
- [小芒森](petit-manseng.md) — 法国西南部 Jurançon 的白葡萄，果粒小、皮厚、晚熟，带热带水果、柑橘、蜂蜜与高酸；可酿甜型、半干与干型，是法国最耐陈年的白葡萄之一。
- [小维多](petit-verdot.md) — 波尔多混酿中的“少数派”红葡萄，晚熟、皮厚、颜色深、单宁强；在凉爽的波尔多常难完全成熟，但在澳大利亚、西班牙与美国常被用来增加结构与颜色。
- [白皮诺](pinot-blanc.md) — 白皮诺是黑皮诺的白色变异，酸度中等偏高、风格温和；在阿尔萨斯常与欧塞瓦混酿，在德国称魏斯堡格，在意大利上阿迪杰称皮诺比安科，既可酿静止干白，也可用于起泡酒。
- [灰皮诺](pinot-gris.md) — 黑皮诺的灰色果皮变种，早熟、皮薄、酸度偏低；在阿尔萨斯可酿出饱满浓郁的风格，在意大利则以清爽轻盈的灰皮诺（Pinot Grigio）为主流。意大利于 2017 年设立 delle Venezie DOC，进一步扩大了这一风格的产量。
- [莫尼耶皮诺](pinot-meunier.md) — 莫尼耶皮诺是黑皮诺的深色变异，发芽早、成熟早，在香槟的黏土坡地上表现稳定；它为混酿提供红色果味与圆润口感，近年单酿与黑中白香槟越来越受关注。
- [黑皮诺](pinot-noir.md) — 皮薄、色浅、酸度高的红葡萄品种，对气候与栽培极为敏感；它是勃艮第红酒与香槟的重要原料，风格从轻盈果味到复杂陈年都有可能。
- [皮诺塔吉](pinotage.md) — 1925 年由南非斯泰伦博斯大学的 Perold 将黑皮诺与神索杂交而成；果色深、单宁结实，风格从鲜亮果味到咖啡、烟熏不等，是南非最具代表性的红葡萄品种，也是 20 世纪人工育种成功的少数红葡萄之一。
- [匹格普勒](piquepoul.md) — 法国朗格多克的白葡萄，核心是 Picpoul de Pinet；高酸、柠檬、海盐与白花，适合配牡蛎与海鲜，是地中海“海水感”白葡萄酒的代表。
- [普拉瓦茨马里](plavac-mali.md) — 克罗地亚达尔马提亚海岸的红葡萄，由 Tribidrag（即仙粉黛）与 Dobričić 杂交而来；高单宁、高酒精、带黑莓、干果与香料，Dingač 是核心产区。
- [雷司令](riesling.md) — 高酸度、香气清晰的白色葡萄品种，以青柠、青苹果与陈年后的矿物、汽油气息著称；德国、阿尔萨斯与奥地利是核心产区，甜度跨度极大。
- [白羽](rkatsiteli.md) — 格鲁吉亚最古老的白葡萄之一，酸度高、带青苹果、白花与香料；可酿清爽干白，也可用陶罐带皮发酵成琥珀色葡萄酒，是格鲁吉亚陶罐传统的核心品种。
- [胡珊](roussanne.md) — 北罗讷河谷的白葡萄，带白花、杏仁、蜂蜜与草药香气，酸度比玛珊高、产量低；常与玛珊混酿，也在萨伏依与朗格多克种植。
- [桑娇维塞](sangiovese.md) — 意大利托斯卡纳的代表性红葡萄品种，酸度高、单宁中等，带酸樱桃、番茄叶与泥土气息；它是基安蒂与布鲁奈罗的核心品种。
- [萨佩拉维](saperavi.md) — 格鲁吉亚卡赫季的红葡萄，以红肉果皮（teinturier）带来的深色与高酸著称；可酿干红、半干、甜型与起泡，是格鲁吉亚葡萄酒的国家标志。
- [长相思](sauvignon-blanc.md) — 香气外放的白葡萄品种，以柑橘、青草、醋栗与热带水果气息著称；酸度高、适合凉爽产区，在卢瓦尔、波尔多与新西兰表现各异。
- [赛美蓉](semillon.md) — 法国波尔多的白葡萄品种，果皮薄、酸度偏低，易受贵腐菌侵染，是苏玳与巴萨克甜白的主体品种，也用于格拉夫的干白；以柠檬、蜂蜡、蜂蜜与杏子香气著称。1855 年分级中，滴金酒庄是唯一获得 Premier Cru Supérieur 的酒庄。
- [圣劳伦特](st-laurent.md) — 中欧的红葡萄，可能与黑皮诺有亲缘；酒色深、酸度高、单宁中低，带黑樱桃、蓝莓、香料与泥土，风格介于黑皮诺与蓝弗兰克之间。
- [西万尼](sylvaner.md) — 原产中欧的白葡萄，在阿尔萨斯、德国与奥地利种植；酒体中等、酸度中高，带青苹果、白花、草药与矿物，常被低估。
- [西拉](syrah.md) — 深色、单宁充沛的红葡萄品种，带黑胡椒、黑莓与紫罗兰气息；原产于法国罗讷河谷，在澳大利亚以 Shiraz 之名广泛种植。
- [丹娜](tannat.md) — 原产法国西南部马迪朗一带的红葡萄，以高单宁、深色与强陈年潜力著称；在乌拉圭成为国家标志品种，常与梅洛、品丽珠混酿以柔化结构。
- [丹魄](tempranillo.md) — 西班牙的代表性红葡萄品种，果皮较厚、成熟较早，带樱桃、皮革与烟草气息；里奥哈与杜埃罗河岸常用橡木桶陈酿塑造其结构。
- [特浓情](torrontes.md) — 阿根廷的原生白葡萄，以玫瑰、柑橘、荔枝与香料香气著称；高海拔萨尔塔版本酸度更高、香气更集中，常被误认为麝香家族。
- [特雷比奥罗（白玉霓）](trebbiano.md) — 意大利与法国广泛种植的白葡萄，高酸、低酒精、风味中性；在意大利叫特雷比奥罗，在干邑与雅文邑则是蒸馏用的白玉霓（Ugni Blanc）。
- [特鲁索](trousseau.md) — 法国汝拉的红葡萄，酒色浅、酸度高、单宁低，带红樱桃、香料与泥土；可酿轻红、桃红与起泡，是汝拉“轻酒体”传统的核心。
- [弗德乔](verdejo.md) — 西班牙卢埃达产区的白葡萄，带茴香、柑橘、白花与草本香气，酸度清爽；常与长相思、维欧尼混酿，是西班牙现代白葡萄酒的核心品种。
- [维蒙蒂诺](vermentino.md) — 地中海沿岸的白葡萄，在撒丁岛、利古里亚、托斯卡纳与法国普罗旺斯（称 Rolle）种植；带柑橘、白花、海盐与草药，酸度中高，适合海鲜。
- [维欧尼](viognier.md) — 原产于法国北罗讷的白葡萄品种，果皮较厚、酸度偏低、香气浓郁；在孔德里约可酿出饱满的杏与金银花风格，也常少量混入西拉以增添香气与颜色稳定。20 世纪中期一度濒临消失，1965 年前后孔德里约仅剩约 30 公顷。
- [沙雷洛](xarel-lo.md) — 西班牙佩内德斯与卡瓦起泡酒的核心白葡萄，酸度高、带青苹果、柑橘、白花与矿物；与马卡贝奥、帕雷亚达构成卡瓦经典三元组合。
- [希诺马罗](xinomavro.md) — 希腊北部纳乌萨的红葡萄，以高酸、高单宁、番茄与橄榄气息著称，常被称为“希腊的內比奥罗”；陈年后带皮革、干果与香料。
- [仙粉黛](zinfandel.md) — 原产于克罗地亚达尔马提亚的红色品种，与意大利普里米蒂沃为同一基因型；19 世纪传入美国，成为加州老藤与高酒精风格的代表。果粒成熟不均，常带黑莓果酱、黑胡椒与干草气息。
- [茨威格](zweigelt.md) — 奥地利最重要的红葡萄，由蓝弗兰克与圣劳伦特杂交而来；早熟、产量高，酒色深、单宁低，带黑樱桃、香料与紫罗兰，适合年轻时饮用。
