# 路线

- [阿尔萨斯特级园路线：凯泽斯堡与里屈埃维尔](alsace-grand-cru-trail.md) — 从凯泽斯堡的魏恩巴赫酒庄到里屈埃维尔的雨格酒庄，两站都在孚日山脉的雨影之下。路线围绕 51 个特级园、四种高贵品种与迟摘、贵腐精选的标签逻辑展开，车程短，却能把阿尔萨斯的结构讲清楚。
- [雅文邑路线：下雅文邑的单一庄园](armagnac-trail.md) — 从热尔省索尔贝的洛巴德，到朗德省阿尔泰兹达尔马尼亚克的奥尼奥阿，两座单一庄园沿下雅文邑的沙质土排开：一座用 1974 年的连续蒸馏器与三千只酒桶做年份，一座从中世纪领地变成朗德省的产区窗口。路线把连续蒸馏、年份酒标与加斯科涅乡间串成一天半。
- [巴巴多斯朗姆路线：圣露西与圣菲利普的双厂车程](barbados-rum-trail.md) — 从北端圣露西的芒特盖到东南圣菲利普的四方，两站车程约一小时多，却分别用 1703 年以来的自流井水与壶式、柱式并行讲连续性，用旧糖厂的开放式参访与不添加糖的主张讲透明度。
- [巴罗萨葡萄酒路线](barossa-wine-trail.md) — 从阿德莱德山麓的奔富玛吉尔庄园出发，沿北东公路进入伊甸谷的亨施克酒庄；一条路线串起 1840 年代移民史、巴罗萨谷底与高海拔带的老藤西拉，以及奔富以试验推动的风格传统。
- [巴伐利亚啤酒路线：慕尼黑到班贝格](bavaria-beer-trail.md) — 从慕尼黑老城的皇家啤酒屋，到西侧厂区一带的奥古斯丁啤酒厂，再乘火车到班贝格老城的施伦克拉烟熏啤酒馆。两站在慕尼黑、一站在班贝格，建议分两天走，用三种空间理解巴伐利亚啤酒文化。
- [比利时啤酒路线：兰比克与布鲁日城市艾尔](belgium-beer-trail.md) — 先在布鲁塞尔安德莱赫特看康帝隆把发酵交给空气，再乘火车到布鲁日，在半月酒厂看酵母被收进罐里。一天之内用两种发酵逻辑，理解比利时啤酒为什么难以被一句话概括。
- [波尔多左岸路线：从葡萄酒城到波亚克两座一级庄](bordeaux-left-bank-chateaux.md) — 先在巴卡朗码头上的葡萄酒城建立世界葡萄酒与波尔多的框架，再乘区域列车北上波亚克，看拉菲与木桐两座一级庄的葡萄园、宅邸与参观边界。三站层层收窄，从“葡萄酒文明”走到“一个村庄的两块砾石坡”。
- [勃艮第路线：博讷老城、默尔索与酒商文化](burgundy-grands-crus-drive.md) — 从博讷主宫医院的慈善医院空间出发，开车南下默尔索看城堡与地下酒窖，再回到博讷老城的约瑟夫杜鲁安，走一遍城市、乡村庄园与酒商三种空间。三站都不以“名庄打卡”为重点，而是理解勃艮第如何把地块、建筑与交易绑在一起。
- [坎贝尔镇威士忌路线：两条街之间的两家酒厂](campbeltown-whisky-trail.md) — 在苏格兰最小的法定产区内，用步行把 Well Close 的云顶与 High Street 的格兰帝串起来。两站相距不到一公里，却分别代表“整条生产线留在厂内”与“维多利亚厂房多次易主后仍守着老尺度”两种生存方式，也把坎贝尔镇从繁荣到收缩的历史压缩在半天里。
- [香槟路线：埃佩尔奈香槟大道步行](champagne-avenue-walk.md) — 在埃佩尔奈一条约一公里半的街道上，把香槟的“房子”与“山丘”放在一起看。先沿大道读立面、庭院与地下酒窖入口，再进酩悦的二十八公里画廊，最后走到巴黎之花，看新艺术宅邸、地下酒窖与以霞多丽为骨架的香槟。
- [干邑路线：干邑镇与雅尔纳克之间的酒庄带](cognac-trail.md) — 沿夏朗特河十余公里的酒商带，两站都在干邑镇内：轩尼诗码头游客中心与人头马老宅。一条线看大酒商如何用十条线路经营品牌，另一条线看 Fine Champagne 如何把原料承诺拆到三处参观点；背景是六大 cru、白玉霓、二次蒸馏与 VS/VSOP/XO 分级。
- [古巴朗姆路线：哈瓦那与圣地亚哥的两座朗姆博物馆](cuba-rum-trail.md) — 从哈瓦那老城港口大道 262 号的品牌博物馆，到圣地亚哥圣巴西利奥街 358 号的地方产业博物馆。两城相距八百多公里，共用一条从 aguardiente 到 ron、从 1862 年到国有化与出口体系的线索。
- [都柏林酒馆路线：从下桥街走到圣詹姆斯门](dublin-pub-trail.md) — 从利菲河南岸的铜头酒馆出发，沿河向西步行到健力士仓库。一站是日常酒馆里的生啤，一站是旧发酵车间改成的品牌展馆，用半天时间看都柏林如何分别经营同一杯黑色啤酒。
- [爱尔兰威士忌路线：海岸、城市与中部小镇](ireland-whiskey-trail.md) — 从安特里姆海岸的布什米尔斯出发，南下都柏林弓街的旧酒厂，再折向中部基尔伯根的老厂。三站分别代表仍在生产的酒厂、已停产改作展馆的酒厂，以及靠社区修复重新出酒的小镇酒厂，一条自驾线把爱尔兰威士忌的三段时间放在同一趟旅程里。
- [艾雷岛路线：南岸泥煤威士忌三家酒厂](islay-whisky-trail.md) — 从 Port Ellen 出发，沿南岸步道依次走到 Lagavulin、Ardbeg 与 Laphroaig。三家酒厂相距不远，风格却从“重泥煤、慢蒸馏”走到“带海水与药味的泥煤”，一条步道就能把艾雷岛南岸的风、海、麦与火串起来。
- [日本路线：从山崎蒸馏所到伏见、西宫的清酒酒藏](japan-sake-kura-trail.md) — 先把日本威士忌的起点放在山崎，再沿铁路到京都伏见的月桂冠大仓酒藏，最后到西宫的白鹿酒藏。三站都用“水”把工艺串起来：山崎的泉水、伏见的软水、西宫的滩五乡水运，构成一条从蒸馏到酿造的对照路线。
- [日本威士忌路线：坐铁路从山崎到白州](japan-whisky-trail.md) — 山崎与白州同属三得利，却分处大阪府与山梨县，中间隔着大半条本州岛。这条路线不租车，用 JR 与接驳巴士把两座蒸馏所串起来：先在京都西南看日本最早的麦芽威士忌蒸馏所，再到南阿尔卑斯山脚看一座建在森林里的蒸馏所，比较两套水、两种气候与两种原酒策略。
- [赫雷斯雪莉路线：一座城、两家酒庄与三条陈年路径](jerez-sherry-route.md) — 从阿科斯街的卢士涛步行到曼努埃尔·马利亚·冈萨雷斯街的冈萨雷斯·比亚斯，两站都在赫雷斯-德拉弗龙特拉；串起 solera 叠桶、flor 生物陈年与氧化陈年的分岔，写清顺序、步行与短途车程、预约季节、配餐与酒后驾驶边界。
- [鹿儿岛烧酒路线](kagoshima-shochu-route.md) — 从枕崎的花渡川蒸馏所明治藏，到都城志比田町的雾岛工厂花园；两站以甘薯为原料，串起白曲与黑曲、常压与减压蒸馏、25 度与 20 度的度数分界，以及甕仕込与甕贮藏。
- [肯塔基波本路线：法兰克福、巴兹敦与洛雷托的三座厂区](kentucky-bourbon-trail.md) — 从法兰克福的水牛足迹，到巴兹敦的天堂山，再到洛雷托的美格。三站构成一个三角，车程分别约一小时、半小时和一个多小时，分别回答大产能多品牌、家族配方矩阵与小麦农场三条不同的波本路径。
- [卢瓦尔白诗南路线：武弗雷与萨韦尼耶尔](loire-chenin-trail.md) — 从武弗雷的休埃酒庄到萨韦尼耶尔的塞朗河畔坡地，两站沿卢瓦尔河中段展开。这条路线用白诗南的干型、半干、贵腐与起泡多面性，以及两座酒庄的生物动力法实践，串起 Vouvray 与 Savennières 两种截然不同的白诗南表达。
- [伦敦经典酒吧步行路线](london-classic-bar-walk.md) — 从萨沃伊的美式酒吧出发，经梅费尔的康诺特酒吧与圣詹姆斯的杜克斯酒吧，最后到舰队街的柴郡奶酪酒馆。三间酒店酒吧对照一间历史酒馆，以步行与短程出租车串联，适合傍晚出发、持续到夜间。
- [伦敦金酒路线](london-gin-route.md) — 以梅菲尔与圣詹姆斯的两家经典酒吧为停靠点，读伦敦金酒从 18 世纪蒸馏立法到当代金汤力的变化；重点不是喝多少杯，而是看酒单如何把杜松子、柑橘与香料写成不同风格。
- [马德拉酒路线：丰沙尔市中心的两种酒商面孔](madeira-wine-route.md) — 丰沙尔市中心步行串联布兰迪酒庄与恩里克斯与恩里克斯：一处是修道院改建、面向访客的酒窖，一处是 1850 年创立、仍自营 Quinta Grande 葡萄园的酒商；两站合起来把“马德拉为什么耐放”讲成工艺问题，并给出预约、邮轮人流与配餐建议。
- [茅台镇白酒路线：从酒文化城到茅台酒厂](maotai-baijiu-town.md) — 在贵州仁怀茅台镇用一天读酱香型白酒：先到中国酒文化城看酒源、酒技与酒俗，再到赤水河畔的茅台酒厂理解核心产区、生产节律与参观边界；路线同时处理预约、品鉴、购买与镇内交通。
- [玛格丽特河葡萄酒路线](margaret-river-wine-route.md) — 从珀斯南下玛格丽特河，以法塞尔与露纹两座先锋酒庄为锚点；一天里看海洋性气候、1970 年代建园史、Art Series 酒标与露纹音乐会，以及 Bussell Highway 两侧的桉树林与葡萄园。
- [马尔堡葡萄酒路线](marlborough-wine-trail.md) — 以布伦海姆的云雾之湾与塞登的伊兰兹为两站的自驾路线，从 Wairau Valley 的老河床砾石走到 Awatere Valley 的沿海风带，用同一天对照马尔堡长相思的两种成熟节奏与两种酒庄叙事。
- [麦克拉伦谷葡萄酒路线](mclaren-vale-wine-route.md) — 从阿德莱德南下麦克拉伦谷，以达伦堡与维拉维拉两座历史酒庄为锚点；一天里看地中海气候、百年石造酒窖、西拉与多品种混酿，以及“立方体”式的当代酒庄建筑。
- [门多萨葡萄酒路线](mendoza-wine-trail.md) — 从卢汉德库约的卡氏家族酒庄到迈普的苏卡尔迪家族基地，一条位于门多萨 Primera Zona 的自驾线；沿路理解 1,500 米高海拔、安第斯融雪滴灌与 Malbec 的三级海拔带。
- [墨西哥龙舌兰路线](mexico-tequila-trail.md) — 从阿马蒂坦的埃拉杜拉庄园到特基拉镇的福塔莱萨，两站都落在火山低地的蓝色龙舌兰核心带。前者用砖砌穹顶炉、野酵母与现代磨机延续大庄园规模，后者用塔霍纳、木槽与两只老铜壶维持小批量，路线还串起 CRT 与 NOM-006 的判断框架。
- [摩泽尔雷司令路线：中摩泽尔与萨尔的两座陡坡酒庄](mosel-riesling-trail.md) — 从贝恩卡斯特-库斯的卢森博士酒庄到维尔廷根的伊贡·米勒酒庄，两站沿摩泽尔与萨尔河谷展开。这条路线用板岩坡地、陡坡人工与雷司令的残糖分级，串起中摩泽尔的地块组合与沙兹霍夫山的单一名园。
- [纳帕谷路线：1976 年巴黎审判之后的现代酒庄带](napa-valley-wine-route.md) — 从罗伯特·蒙大维的 To Kalon 葡萄园出发，到蒙大维与菲利普·德·罗思柴尔德男爵合办的 Opus One，最后回到 1876 年创立的贝灵哲。三站都在 St Helena Highway 沿线，却分属“现代纳帕的起点”“跨大西洋合资”与“禁酒令前的老酒庄”三种时间。
- [纽约历史酒馆路线：东村到格拉梅西](new-york-historic-pubs.md) — 从东村的麦克索利老麦酒馆出发，经西村的白马酒馆，最后到格拉梅西公园旁的皮特酒馆。三间老酒馆各有不同的“老”，以地铁与步行为主，适合下午到傍晚的半日路线。
- [瓦哈卡梅斯卡尔路线](oaxaca-mezcal-trail.md) — 先在瓦哈卡市中心的梅斯卡尔图书馆建立品种与村子的坐标，再南下圣卡塔里娜米纳斯的雷亚尔米内罗看土坑、木槌与陶罐。两站之间是中央谷地的 Espadín 田、圣地亚哥马塔特兰的 palenque 群，以及 NOM-070 划出的底线。
- [皮埃蒙特巴巴莱斯科路线](piedmont-barbaresco-trail.md) — 从巴巴莱斯科村的嘉雅到塞拉伦加达尔巴的丰塔纳弗雷达，两站相距约半小时，串起内比奥罗、巴巴莱斯科与巴罗洛的法定差异、朗格的雾与晚收，以及单园与橡木的争论。嘉雅参观政策未公开确认，出发前须联系官方。
- [波特与杜罗路线：从萨布罗萨的老藤到皮尼昂的国家园](porto-douro-route.md) — 沿杜罗河右岸自驾，从萨布罗萨 Gouvinhas 的克拉斯托到皮尼昂的诺瓦尔，两站都在片岩坡地上、都同时做杜罗 DOC 与波特，却分别讲“整片地产的家族接力”和“一块未嫁接地块的连续性”；含地址顺序、车程、预约季节与吐酒驾驶建议。
- [布拉格啤酒路线：从弗勒克到小熊](prague-beer-trail.md) — 从只酿一款深色拉格的弗勒克啤酒屋，步行到把微型酒厂塞进老城的小熊酒馆。两站相距不到一公里，却把布拉格啤酒的两种性格放在同一个下午：一种酒做到熟，和一个小厂做到全。
- [普罗旺斯桃红路线](provence-rose-trail.md) — 从塔拉多的 Château de Selle 到科朗斯的米拉沃，两站相隔约一小时，用一天时间对照普罗旺斯桃红的两种路径：一处开放酒窖、按预约接待；一处私家庄园、只通过渠道出售。路线同时解释米斯特拉尔风、石灰岩与片岩，以及浅色桃红的直接压榨工艺。
- [青岛啤酒路线：博物馆、老厂区与登州路啤酒街](qingdao-beer-trail.md) — 从青岛啤酒博物馆的百年厂房与老设备开始，走到同一厂区仍在运转的生产廊道，再出门进入登州路啤酒街，用一扎原浆和一份辣炒蛤蜊收尾。三站相距很近，讲的却是三件事：工业史、仍在工作的工厂、城市夜生活。
- [里奥哈哈罗车站区酒庄路线：三家百年酒庄与长时间陈年](rioja-haro-bodegas.md) — 从洛佩兹雷迪亚出发，步行到里奥哈阿尔塔，再到 CVNE。三家庄园都挤在阿罗火车站旁的一小片街区里，却分别代表极端传统、经典长陈年与家族品牌三条路径；路线讲清车站区历史、美国桶传统、预约与火车到达。
- [广岛西条酒藏路线](saijo-sake-route.md) — 从贺茂鹤一号藏步行到贺茂泉延寿藏，两站都在西条酒藏通的一公里余范围内；以七家酒藏的产业聚落、软水与山田锦、冬季酿造、吟酿与纯米吟酿的标签区别，以及春季酒藏开窖活动为线索。
- [圣日耳曼德佩文学咖啡馆半日路线](saint-germain-literary-cafes.md) — 以巴黎圣日耳曼德佩广场为中心的两站步行路线：先在双叟咖啡馆坐看广场，再横过街口到花神咖啡馆。两店相距很近，适合半日慢走，不适合赶景点。
