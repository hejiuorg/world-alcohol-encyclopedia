# 技法

[返回中文目录](../README.md)

- [盲品](blind-tasting.md) — 在不看标签的情况下，通过香气、口感、结构与余味推断酒的类型、产区、年份与品质；关键是系统方法，而不是“猜对”。
- [醒酒](decanting.md) — 把酒液与沉淀分离、并让酒与空气接触的侍酒技法；是否需要醒酒取决于酒种、酒龄与状态，不是所有酒都适合长时间醒酒。
- [双重过滤](double-straining.md) — 先用主滤器挡住冰块与大块固体，再经细滤网滤除果肉、碎叶与冰屑的技法；换来更干净的口感与外观，但速度更慢。
- [干摇](dry-shaking.md) — 不加冰先摇、再加冰湿摇的两段式技法；常用于含蛋清、奶油或植物蛋白的配方，目的是先形成稳定泡沫再冷却稀释。
- [烧皮](flaming-zest.md) — 把柑橘皮油挤过火焰、让油雾短暂燃烧并落入杯中的技法；带来烘烤香气与戏剧性，但属于明火操作，安全优先。
- [分层](layering.md) — 利用液体密度差异，让不同原料在杯中形成可见层次的调酒技法；依靠缓慢倾倒与配方顺序，而不是靠搅拌。
- [捣压](muddling.md) — 用捣棒在杯中轻压香草、水果或糖块，使香气与汁液释放的调酒技法；关键在“压开而不撕碎”，过度用力会带来苦涩与浑浊。
- [闻香](nosing.md) — 借助杯口聚集的香气判断酒的状态、层次与强度的品鉴技法；应先静后动、由远及近，并记录具体气味，而不是只留下“好闻”或“不好闻”的印象。
- [观察颜色](observing-colour.md) — 在统一背景与光线下观察酒液的澄清度、色调与浓度，为酒龄、品种与工艺提供线索的品鉴技法；颜色只能作为线索，不能单独用来判断质量。
- [开瓶（软木塞）](opening-cork.md) — 用开瓶器完整取出软木塞、避免碎屑落入酒液并检查瓶塞状态的侍酒技法；关键是螺旋居中、提拉稳定、老酒用专门工具。
- [开瓶（起泡酒）](opening-sparkling-wine.md) — 安全打开带压起泡酒的侍酒技法；核心是充分降温、保持瓶身稳定、用手控制瓶塞，让气体轻声释放而不是把塞子冲飞。
- [倒酒](pouring.md) — 把酒液从瓶中定量倒入杯中的侍酒技法；目标是控制酒量、减少沉淀搅动、保留气泡并保持卫生，而不是把杯子倒满。
- [滚酒](rolling.md) — 把酒液在两个容器之间反复来回倾倒的混合技法；比摇和温和、比搅拌充气更多，适合配方明确要求滚酒的酒款。
- [军刀开香槟](sabrage.md) — 用军刀沿香槟瓶颈的接缝快速滑开瓶口，利用瓶内压力让瓶口与瓶塞一起飞出；需要冰镇、稳瓶与安全距离。
- [摇酒](shaking.md) — 把原料与冰块放入摇酒壶中快速摇晃，使酒液冷却、稀释并均匀混合的调酒技法；与搅拌相比，摇和带来更多充气与稀释。
- [入口](sipping.md) — 用少量酒液覆盖口腔、在数秒内评估甜度、酸度、酒体、单宁、酒精与余味的品鉴技法；入口量小、停留短、条件固定，才便于比较。
- [吐酒](spitting.md) — 专业品鉴中把酒液在口中充分接触后吐出的技法；目的是保持清醒、控制酒精摄入并连续品评多款酒，而不是表示厌恶或浪费。
- [搅拌](stirring.md) — 把原料与冰块放入调酒杯，用吧勺沿杯壁稳定搅拌，使酒液冷却、适度稀释并均匀混合的调酒技法；与摇和相比，搅拌充气少、成品更清澈。
- [温度控制](temperature-control.md) — 通过冷藏、冰桶、室温回温与储存管理，让酒液在合适温度饮用；温度影响香气、气泡、口感与发酵，稳定比绝对数值更重要。
