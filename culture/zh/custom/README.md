# 礼俗

[返回中文目录](../README.md)

- [寿酒](birthday-wine.md) — 寿酒是生日与整寿宴席上的敬老之酒，兼具祝福、答谢与家族聚会功能。本文说明做九不做十、寿堂与寿桃、千秋节与千叟宴等历史节点，并讨论高龄饮酒与劝酒的边界。
- [寒食节与酒](cold-food-festival-wine.md) — 寒食在清明前一二日，以禁火冷食、祭墓踏青为核心；酒在其中多承担奠酒与家宴的角色，而非固定的节令配方。本文梳理时间地域、来源流变、酒器食物与当代实践，并说明冷食与饮酒的健康边界。
- [重阳菊花酒](double-ninth-chrysanthemum-wine.md) — 重阳菊花酒是农历九月初九的节令酒，与登高、佩茱萸、赏菊、敬老连成一套动作。本文梳理文献所记的酿造与浸泡两系做法、地域差异、历史层累，并说明药效说法与自制风险的边界。
- [端午雄黄酒](dragon-boat-realgar-wine.md) — 端午饮雄黄酒、洒雄黄水、以雄黄画额，是汉族地区有文献记载的节令习俗。雄黄含砷，加热还会生成毒性更强的三氧化二砷；本文分开讲习俗来源、象征与安全边界，并给出今天可用的替代做法。
- [满月酒](full-moon-feast.md) — 满月酒是婴儿出生满一个月时的宴请，兼具报喜、答谢、命名与社交功能。本文说明宋代“洗儿会”与近世满月宴的联系、各地流程差异、酒的角色，并提示哺乳期与婴儿安全边界。
- [丰收酒与葡萄收获节酒俗](harvest-wine.md) — 丰收酒是秋收之后谢神、尝新与村宴上的酒；在欧洲葡萄产区，采收季又以葡萄收获节的形式延续。本文比较中国与欧洲两种“丰收饮酒”的时间、仪式、酒器与食物，并讨论旅游化与过量饮酒的边界。
- [乔迁酒](housewarming-wine.md) — 乔迁酒是新居落成或搬家之后请亲友到家中聚饮的习俗，北方常叫“温锅”“燎锅底”，南方多说“入伙”。它把安家的喜悦、邻里关系和人情往来放在一张桌子上，也带来劝酒、攀比与装修污染等现实问题。
- [中秋赏月酒](mid-autumn-moon-wine.md) — 农历八月十五赏月、祭月与饮酒的组合习俗；酒既是供品与团圆饮品，也是文学意象与节前新酒上市的节点，文献记载与当代实践需分开看。
- [年节饮酒：椒柏酒与屠苏酒](new-year-wine.md) — 正月初一饮椒柏酒、屠苏酒，是至少可追溯到南北朝的岁时习俗；《荆楚岁时记》还记下“饮酒次第，从小起”的次序。酒在这里是驱疫、祝岁与家族礼序的组合，不只是节庆助兴。
- [祭酒](sacrificial-wine.md) — 祭酒是祭祀中献给祖先、神灵与先贤的酒，讲究洁净、器物与次序。本文比较家祭、墓祭与公祭的流程差异，解释三献、酹酒等动作，并讨论当代简化、环保与“祭酒”一词的常见误读。
- [婚宴酒俗：从合卺到交杯酒](wedding-wine.md) — 合卺是先秦婚礼中的共饮仪式，《礼记·昏义》说“合卺而酳”，《仪礼·士昏礼》记“三酳用卺”。后世把它演成交杯酒，但古今仪式、器物与含义并不完全相同。
- [中元节与酒](zhongyuan-festival-wine.md) — 中元节在农历七月十五，道教称中元、佛教称盂兰盆，民间以祭祖、烧纸、放河灯为核心；酒主要用于奠酒与家宴，是把思念变成动作的媒介。本文同时讨论地域差异、历史来源与当代争议。
