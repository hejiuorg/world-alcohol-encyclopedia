# 诗词

[返回中文目录](../README.md)

- [问刘十九：白居易的一杯冬夜酒](bai-juyi-asking-liu.md) — 白居易《问刘十九》只有四句二十字：新酿的绿蚁酒、红泥小火炉、将雪的傍晚，以及一句“能饮一杯无”。它把请客写成一幅有温度的冬夜小画，分寸感比酒本身更耐读。
- [短歌行：曹操把酒写成了求贤的忧思](cao-cao-duan-ge-xing.md) — 《短歌行》是乐府旧题，传统归在曹操名下。诗从“对酒当歌，人生几何”写起，以酒解忧，转入求贤的焦虑，最后以周公吐哺收束。酒在诗里不是享乐，而是把短促人生与未竟事业放在同一张桌上的媒介。
- [登高：杜甫在夔州登台的一杯浊酒](du-fu-deng-gao.md) — 杜甫《登高》写于大历二年（767）夔州，八句七律，前四句写秋景，后四句写身世，末句落在“新停浊酒杯”。酒没有出现在宴席上，而是以“停”的方式出现，成为年老、多病与漂泊的标记。
- [客至：杜甫在草堂请客的一顿饭](du-fu-ke-zhi.md) — 杜甫《客至》约作于上元二年（761）春成都草堂，题下自注“喜崔明府相过”。诗从春水群鸥写到扫径开门，再从市远无兼味写到家贫只旧醅，把一顿不丰盛的请客写得诚恳而温暖。
- [清明：一场雨、一个行人和一处酒家](du-mu-qingming.md) — “清明时节雨纷纷”四句二十八字，写雨中的行人与牧童指路，酒家只被问到、没有被走到。这首诗长期署名杜牧，但《樊川文集》未收，最早见于南宋类书，作者归属仍有争议；杏花村也未必是某个确定地名。
- [渔家傲·秋思：范仲淹在边城的一杯浊酒](fan-zhongyan-yu-jia-ao.md) — 《渔家傲·秋思》写西北边塞的秋天：雁去无留意，边声四起，孤城紧闭；下片以“浊酒一杯家万里”写乡愁，以“燕然未勒归无计”写功业未成，最后落在“将军白发征夫泪”。一杯酒量出了家与边关的距离。
- [月下独酌：李白的一壶酒与三个影子](li-bai-drinking-alone.md) — 李白《月下独酌》以“举杯邀明月，对影成三人”把孤独写成一场小剧场：月亮与影子不会饮酒，却被诗人拉来作伴。酒在这里不是消愁的工具，而是搭起想象舞台的道具。
- [客中作：李白在兰陵的一碗琥珀酒](li-bai-kezhong-zuo.md) — 《客中作》只有四句二十八字：兰陵美酒、玉碗、琥珀色的酒光，以及一位让客人忘记身在异乡的主人。诗里的“郁金香”指浸酒用的郁金，不是荷兰郁金香花；酒是低度发酵的谷物酒，不是今天的白酒。
- [将进酒：李白的劝饮与时间](li-bai-qiang-jin-jiu.md) — 《将进酒》是乐府旧题，约作于天宝年间；李白借劝酒写时间的不可逆、才华的自信与失意的排解。通行本与敦煌写本《惜罇空》文字有差异，“三百杯”是文学夸张而非酒量记录。
- [声声慢：三杯两盏淡酒，怎敌他晚来风急](li-qingzhao-sheng-sheng-man.md) — 李清照《声声慢》以十四个叠字开篇，写乍暖还寒的秋日、三杯两盏淡酒、满地残花、梧桐细雨。酒在这里既不能暖身，也不能消愁，“淡”与“敌不过”把整首词的无力感定了下来。
- [醉花阴：李清照重阳把酒的一天](li-qingzhao-zui-hua-yin.md) — 李清照《醉花阴》写一个重阳节从白昼到黄昏的过程：薄雾浓云、香炉、玉枕纱帐、东篱把酒，最后落在“人比黄花瘦”。酒只出现一次，却把整日的闲愁与身体的消瘦连在一起。
- [雨霖铃：柳永在都门外喝不下的一杯送别酒](liu-yong-yu-lin-ling.md) — 《雨霖铃·寒蝉凄切》写一场秋雨初停的送别：都门外设帐饯行，酒摆在面前却“无绪”，船家催着开船，两人执手落泪。下片设想“今宵酒醒何处”，把一杯没喝好的酒变成“杨柳岸，晓风残月”的清醒。酒在词里不是助兴，而是离别的证据。
- [游山西村：陆游在农家喝的一碗腊酒](lu-you-you-shan-xi-cun.md) — 陆游《游山西村》写一次山村之行：农家腊酒虽浑，待客的鸡豚却足；山路重重，柳暗花明处又见一村；春社将近，箫鼓相随；临别约好，以后要拄杖乘月随时来叩门。酒是农家自酿的浊酒，不是名酒，却是一顿饭的起点。
- [过故人庄：孟浩然在农家喝的一顿便酒](meng-haoran-guo-gu-ren-zhuang.md) — 孟浩然《过故人庄》写一次普通的农家做客：故人备了鸡黍，村边绿树环绕，青山在城外斜立，开窗面对场圃，端起酒杯聊农事，最后约定重阳再来赏菊。酒在诗里不是名酒，而是家常饭桌上的一杯。
- [定风波：一蓑烟雨任平生](su-shi-ding-feng-bo.md) — 苏轼《定风波》写三月七日沙湖道中遇雨：同行狼狈，他独不觉；雨停之后回望来路，写下“也无风雨也无晴”。酒只出现一次——“料峭春风吹酒醒”——却把全词的感受从雨中转向清醒。
- [念奴娇·赤壁怀古：苏轼在黄州把酒酹江月](su-shi-nian-nu-jiao.md) — 《念奴娇·赤壁怀古》作于元丰五年（1082）苏轼贬居黄州时。词从大江东去写到三国周郎，再回到“早生华发”的自己，最后以“一尊还酹江月”收束。酒只在结尾出现，不是痛饮，而是把一杯酒洒向江与月。
- [水调歌头：苏轼中秋把酒问月](su-shi-shui-diao-ge-tou.md) — 苏轼《水调歌头》作于熙宁九年（1076）中秋，小序写明“欢饮达旦，大醉”，并“兼怀子由”。词从把酒问青天写到月照无眠，最后以“但愿人长久，千里共婵娟”收束，把一杯酒放进了对兄弟与对人的祝愿里。
- [桃花庵歌：唐寅用桃花换酒钱](tang-yin-tao-hua-an-ge.md) — 《桃花庵歌》写一个住在桃花庵里的“桃花仙”：种桃树、摘桃花换酒钱，酒醒花前坐，酒醉花下眠，但愿老死花酒间，不愿鞠躬车马前。它把清贫的自在写得夸张而痛快，也用“五陵豪杰墓”反问富贵的长久。此诗版本差异较大，读时需先说明所用文本。
- [饮酒·其五：陶渊明在东篱下看见的南山](tao-yuanming-drinking-wine-5.md) — 《饮酒》其五写结庐人境而无车马之喧，采菊东篱、悠然见山，最后落到“此中有真意，欲辨已忘言”。这首诗本身没有出现“酒”字，酒在组诗的总序与题目里；理解它，需要把饮酒放回陶渊明归田生活的整体。
- [饮酒·其七：秋菊、忘忧物与东轩](tao-yuanming-drinking-wine-7.md) — 《饮酒·其七》从秋菊带露写起，把菊花浮在酒中，借“忘忧物”推开世俗之情；随后写独饮、日落、归鸟与东轩长啸。它是一首关于自足的田园诗，也是一首把酒写得极安静的诗。
- [凉州词：王翰把一杯葡萄酒放在战场边上](wang-han-liang-zhou-ci.md) — 王翰《凉州词》只有四句：葡萄美酒、夜光杯、马上琵琶，以及“醉卧沙场君莫笑，古来征战几人回”。它把最华美的酒器与最残酷的战场放在同一幅画面里，用劝酒的口吻写战争的代价。末句是反问，不是豪言；读它时不宜只取豪迈，而忽略那层悲凉。
- [送元二使安西：一杯酒把送别写成了曲子](wang-wei-song-yuan-er.md) — 王维《送元二使安西》以渭城朝雨、客舍柳色起笔，落到“劝君更尽一杯酒，西出阳关无故人”。它把一场远行压缩进一杯酒，唐代已入乐歌唱，后世又衍为《阳关三叠》，是流传最广的送别诗之一。
- [破阵子：辛弃疾醉里挑灯看剑的一场梦](xin-qiji-po-zhen-zi.md) — 《破阵子·为陈同甫赋壮词以寄之》从“醉里挑灯看剑”写起，梦回连营、沙场点兵、马快弓响，前九句极壮，最后一句“可怜白发生”把梦戳破。酒是入梦的入口，也是壮志难酬的夜间动作。
- [浣溪沙：晏殊在一杯酒里看见时间](yan-shu-huan-xi-sha.md) — 《浣溪沙·一曲新词酒一杯》从听一支新曲、饮一杯酒写起，去年的天气与旧日的亭台还在，夕阳却问“几时回”。下片以“无可奈何花落去，似曾相识燕归来”写消逝与归来，最后落在小园香径里的独自徘徊。酒在这里不是宴饮，而是让人安静下来面对时间的日常动作。

- [酒德颂：刘伶把饮酒写成一篇政治寓言](liu-ling-jiu-de-song.md) — 《酒德颂》借“大人先生”与贵介公子、搢绅处士的对照，把饮酒写成不受礼法约束的生活姿态；酒不是享乐道具，而是魏晋名教与政治高压下的消极抵抗。
- [醉翁亭记：欧阳修写的不是酒，是一套地方治理的心情](ouyang-xiu-zuiweng-ting-ji.md) — 《醉翁亭记》作于庆历六年欧阳修知滁州时，从琅琊山、酿泉写到滁人游与太守宴，最后落到“太守谓谁”。它常被当作山水游记，其实也是一篇关于贬谪、宽简政治与“与民同乐”的地方治理文本。
- [把酒问月：李白问的不是月亮，是人与时间的关系](li-bai-ba-jiu-wen-yue.md) — 《把酒问月》从“停杯一问”写到“今人不见古时月，今月曾经照古人”，月亮是恒常的参照，酒是提问的动作；结尾“月光长照金樽里”把宇宙尺度收回眼前一杯。
- [饮中八仙歌：杜甫写的不是酒量排行榜，是一组盛唐群像](du-fu-yin-zhong-ba-xian-ge.md) — 《饮中八仙歌》以贺知章、汝阳王、左相李适之、崔宗之、苏晋、李白、张旭、焦遂八人为对象，用八段速写写酒后的神态与身份；酒是让人暂时脱离官场、礼法与日常角色的媒介。
- [临江仙·夜饮东坡：一扇敲不开的门，一条听得见的江](su-shi-linjiang-xian-ye-yin-dongpo.md) — 《临江仙·夜饮东坡醒复醉》作于苏轼贬谪黄州时期，从夜饮东坡、醉归临皋写起，家童熟睡、敲门不应，只好倚杖听江声；结尾“小舟从此逝，江海寄余生”不是出走，而是被门挡住的人在江声里想象出口。
- [如梦令·常记溪亭日暮：一首三十三字的小电影](li-qingzhao-ru-meng-ling.md) — 李清照《如梦令》只三十三字，却写了时间、地点、醉意、迷路、惊鸟五个层次；“沉醉”既可能是酒，也可能是景，“争渡”既可能是抢着划，也可能是“怎渡”的疑问。
- [西江月·遣兴：醉里推松，是笑话也是脾气](xin-qiji-xi-jiang-yue-qian-xing.md) — 辛弃疾《西江月·遣兴》写醉后欢笑、醉倒松边、问松“我醉何如”、又推松说“去”；表面是诙谐小词，内里是对“古人书”与南宋政治的愤激。
