# 术语

[返回中文目录](../README.md)

- [酸度（acidity）](acidity.md) — 酸度描述酒中酸类物质的总量与强度，常用总酸（g/L）与 pH 两个不同指标；它支撑清爽感、平衡与陈年潜力，也影响二氧化硫的有效性。
- [酒精度（ABV）](alcohol-by-volume.md) — 酒精度指 20°C 时酒中乙醇的体积分数，通常写作 % vol；它是标签与配方的基础参数，但不是品质评分。
- [天使分享（angel's share）](angels-share.md) — 天使分享指烈酒在橡木桶陈年期间通过桶壁蒸发损失的酒液；苏格兰行业常引每年约 2%，但实际速率受温度、湿度、桶容与仓库类型影响，并非精确常数或品质指标。
- [原产地命名（appellation）](appellation.md) — 原产地命名是把地理范围与生产规范绑定起来的法定标识，如法国 AOC/AOP、意大利 DOC/DOCG、西班牙 DO 与欧盟 PDO/PGI；它说明产地与规则，不等于质量排名。
- [香气（aroma）](aroma.md) — 香气是鼻子感知到的挥发性气味，可按来源分为品种、发酵与陈年三层；它与入口后的风味不同，aroma 与 bouquet 也不是同义词。
- [过桶（barrel finishing）](barrel-finishing.md) — 过桶指主要陈年结束后把酒液转入另一种桶继续存放一段时间，以增加或调整风味；它是二次陈年，不等于全程使用该桶，也不等于桶强。
- [混酿（blend）](blend.md) — 混酿指把不同品种、年份、地块或基酒组合成最终产品，用于平衡结构、稳定风格或满足法规；它是常规工艺，不等于低质量，也不等于“掺假”。
- [酒体（body）](body.md) — 酒体是入口时对酒液“重量”与“饱满度”的感官描述，常分为轻、中、重；酒精、甘油、残糖、单宁、酸度与温度都会影响它，不能只用酒精度判断。
- [白利度（Brix）](brix.md) — 白利度（°Brix）表示 20°C 时溶液中蔗糖的质量分数，1 °Brix 即每 100 克溶液含 1 克蔗糖；它用于葡萄成熟度与发酵监控，不等于酒精度或甜度。
- [桶强（cask strength）](cask-strength.md) — 桶强指装瓶时几乎不加水、保留桶中自然酒精度，常见约 50%–65% vol；它是装瓶方式，不等于单一桶，也不等于更高品质。
- [冷凝过滤（chill filtration）](chill-filtering.md) — 把威士忌降温使长链脂肪酸酯与蛋白质析出再过滤的工序；目的防低温浑浊，是可选工艺，不是法定等级，也不等于滤掉所有风味。
- [围墙园（clos）](clos.md) — clos 指以围墙、篱笆或自然边界围合的葡萄园地块，常见于勃艮第、卢瓦尔与阿尔萨斯；它标识地块边界，不是法定分级，也不等于单一所有者。
- [塔式蒸馏器（column still）](column-still.md) — 塔式蒸馏器是连续蒸馏设备，通过多层塔板实现反复气液交换，可产出高纯度酒精；塔板数、回流比与进料位置决定馏出物的纯度与风味保留。
- [软木塞污染（cork taint）](cork-taint.md) — 软木塞污染主要由 TCA 等卤代苯甲醚造成，表现为潮湿纸板、霉味并压制果香；它在每升数纳克即可被察觉，但不影响饮用安全，也不等于木塞碎屑。
- [精酿啤酒](craft-beer.md) — 20 世纪后期在美国兴起的小型、独立、重传统与创新的啤酒生产与消费现象；它是行业与市场概念，不是法定等级，也不等于高质量。
- [调配（cuvée）](cuvee.md) — cuvée 在起泡酒里可指压榨时最先流出的轻柔汁液，也可指由多个基酒调配成的一批酒；在多数产区它不是法定等级，标签上常只是产品名。
- [醒酒与换瓶（decanting）](decanting.md) — 醒酒（换瓶、滗酒）把酒液从原瓶转移到另一容器，目的有二：分离沉淀与增加氧气接触；老红葡萄酒与年轻单宁酒的目标不同，并非所有酒都适合醒酒，时间长短需按酒龄与状态判断。
- [除渣（disgorgement）](disgorgement.md) — 除渣是传统法起泡酒在转瓶后排出瓶口酵母沉淀的工序，分手工与冷冻瓶颈两种方式；除渣后通常补液（dosage），再封口完成成品。
- [补液（dosage）](dosage.md) — 补液是传统法起泡酒除渣后补入瓶中的调味液，通常由基酒与糖组成；它既补回除渣损失的体积，也决定成品甜度等级，欧盟规则以糖分区间区分 brut nature 到 doux。
- [干型（dry）](dry.md) — 干型是葡萄酒标签上的残糖分级，欧盟通常为不超过 4 g/L，总酸达标时可放宽到 9 g/L；它不描述果味强弱，也不等于质量等级。
- [窖池](fermentation-pit.md) — 固态法白酒的发酵容器，多以黄泥、条石、砖、水泥或木材建成，形状多呈长方体；窖池类型与窖泥状态直接影响酒醅的发酵环境。
- [过滤（filtration）](filtration.md) — 过滤是让酒液通过滤材、物理截留悬浮颗粒与微生物的工序，按结构分为深层过滤与膜过滤；它影响澄清度、稳定性与风味保留，且不等于下胶。
- [下胶（fining）](fining.md) — 下胶是向酒中加入膨润土、蛋清、明胶或合成聚合物等助剂，使其吸附悬浮或溶解的目标物质并沉降，以去除蛋白质、单宁、色素或异味；它是澄清与稳定手段，不等于过滤，也涉及素食与过敏原问题。
- [余味（finish）](finish.md) — 余味是酒液咽下或吐出后，口腔与鼻腔中仍然延续的味觉、香气与触感；长度、层次与干净度共同决定它的质量，长余味不等于质量保证。
- [酒花（flor）](flor.md) — 酒花（flor）是雪莉酒生物陈年时在酒液表面形成的酵母膜，它隔绝氧气并代谢酒精与甘油，改变香气；Fino 与 Manzanilla 依赖酒花，Oloroso 则走氧化陈酿路线。
- [酒头、酒心、酒尾（heads, hearts, tails）](heads-hearts-tails.md) — 一次蒸馏的馏出液按挥发性分为酒头、酒心与酒尾；酒心是乙醇与香气最平衡的中段，是成品主体，酒头与酒尾因杂质多通常回收再蒸，切酒点决定风格。
- [红曲](hongqu.md) — 以大米为原料、接种红曲霉后培养制成的紫红色曲；既是黄酒的糖化发酵剂，也是红曲酒、红糟与食品着色的原料，其桔霉素风险需要过程控制。
- [IBU（国际苦味单位）](ibu.md) — IBU 是啤酒苦度的计量单位，1 IBU 约等于每升 1 毫克异α-酸；它测的是酒花苦味物质，不等于入口感受到的苦味强度，也不等于酒花香气。
- [晚收（late harvest）](late-harvest.md) — 晚收指葡萄在常规成熟期后继续留在藤上、延后采收，通过失水浓缩糖与风味；它可做甜酒，也可能只是高酒精度的干型酒，且不等于贵腐。
- [酒泥（lees）](lees.md) — 酒泥是发酵结束后沉降在容器底部的酵母细胞、果肉残渣与酒石酸盐等固体；保留细酒泥并搅动会改变口感、香气与稳定性。
- [浸渍（maceration）](maceration.md) — 浸渍是果汁与果皮、果肉、种子或果梗保持接触的过程，用于提取颜色、单宁与香气；时间、温度与酒精浓度决定提取的强度与方向。
- [苹果酸-乳酸发酵（malolactic fermentation）](malolactic-fermentation.md) — 乳酸菌把苹果酸转化为乳酸与二氧化碳的二次发酵，会降低酸度、柔化口感；它不同于酒精发酵，也并非所有酒款都需要。
- [糖化醪（mash）](mash.md) — 糖化醪是麦粉与热水在糖化槽中形成的混合物，淀粉在此被酶分解为可发酵糖；它是麦芽汁的前体，不是麦芽汁本身，料水比、温度与 pH 共同决定糖谱与出糖率。
- [气泡质地（mousse）](mousse.md) — 气泡质地（mousse）指起泡酒入杯后泡沫的生成、颗粒粗细与持续时间；瓶内二氧化碳压力通常约 5–6 bar，温度、杯型、酒液成分与带泥陈年共同决定气泡表现，气泡粗细并非质量高低的直接指标。
- [葡萄醪（must）](must.md) — 葡萄醪指葡萄破碎压榨后得到的汁液及悬浮固体，是葡萄酒发酵的起点；其糖度、酸度、含固量与澄清度决定发酵进程和酒款风格。
- [贵腐（noble rot）](noble-rot.md) — 贵腐是灰葡萄孢菌在夜间潮湿、白天干燥的交替条件下侵染成熟葡萄，使果实失水、糖酸与风味浓缩的现象；它用于苏玳、托卡伊等甜酒，与持续潮湿造成的灰腐病不同。
- [原麦汁浓度（original gravity）](original-gravity.md) — 原麦汁浓度指发酵前麦汁中可溶性固形物的浓度，常用 °P（柏拉图度）表示；它反映原料浸出物，不等于酒精度，需与终点密度一起估算酒精。
- [氧化（oxidation）](oxidation.md) — 氧化是酒液中的成分与氧气发生反应，改变香气、颜色与单宁结构；少量受控氧化可以塑造雪利、马德拉、汝拉黄酒等风格，过量则导致果香流失、褐变与乙醛累积。
- [泥煤（peat）](peat.md) — 泥煤是缺氧沼泽中部分分解的植物残体，燃烧产生的酚类会附着在烘烤麦芽上；泥煤味是威士忌的可选风格，不是所有苏格兰威士忌的必备特征。
- [泥煤酚值（PPM）](peat-phenol-ppm.md) — 通常指麦芽总酚含量，1 ppm 即 1 mg/kg；它描述麦芽烟熏规格，不是瓶中酒液浓度或法定泥煤等级。
- [精米步合（polishing ratio）](polishing-ratio.md) — 精米步合指清酒米经研磨后剩余的比例，50% 表示磨去一半、剩下 50%；它与大吟酿、吟酿、本酿造等特定名称等级相关，但不直接等同于质量高低。
- [葡萄渣（pomace）](pomace.md) — 葡萄渣是压榨后剩下的果皮、果肉、种子与果梗等固体，区别于酒泥；它可蒸馏成 grappa、marc 等渣酿烈酒，也可提取酒石酸，但必须尽快处理以防醋化腐败。
- [壶式蒸馏器（pot still）](pot-still.md) — 壶式蒸馏器是分批蒸馏的铜制设备，由加热壶、塔颈与冷凝器构成；壶形、加热方式与切酒点决定酒液的风格走向，并与连续蒸馏形成效率与风味的取舍。
- [标准酒度与 Proof](proof-and-abv.md) — 标准酒度多为 20°C 体积分数；美制 proof 为 60°F 下 ABV 的两倍，100 proof 等于 50% ABV，英国旧制不同。
- [还原（reduction）](reduction.md) — 还原既指尽量隔绝氧气的还原型酿造，也指缺氧条件下生成的硫化氢、硫醇等还原性气味；前者是工艺选择，后者是否构成缺陷取决于浓度与化合物种类。
- [残糖（residual sugar）](residual-sugar.md) — 残糖是发酵结束后酒液中未被酵母转化的糖分，通常以 g/L 计；它决定甜度标签，但甜感还受酸度、酒精、温度与气泡影响。
- [转瓶（riddling）](riddling.md) — 转瓶（riddling，法语 remuage）是传统法起泡酒把二次发酵后的酵母沉淀逐步聚集到瓶口的工序；手工转瓶约需 26–30 天，机械转瓶可缩短到数天，二者在一致性、成本与逐瓶判断上各有取舍。
- [半干（semi-dry）](semi-dry.md) — 半干指残糖高于干型、又未达到半甜或甜型的中间档；具体克数因品类与法规而异，不能只凭口感判断。
- [单一麦芽威士忌（single malt）](single-malt.md) — 单一麦芽指同一酒厂、以 100% 发芽大麦为原料、用壶式蒸馏器生产的威士忌；它与单一谷物、调和麦芽在原料与来源范围上不同，苏格兰对其有法定定义，其他市场多为行业用法。
- [单一品种（single varietal）](single-varietal.md) — 单一品种指以一种葡萄为主体的葡萄酒；标签能否写品种名取决于各国法规，欧盟与澳大利亚多为 85%，美国为 75%，它不是“100% 该品种”的同义词。
- [索莱拉系统（solera）](solera.md) — 索莱拉是分级叠放、逐级取补的陈年体系，底层存放最老的酒，上层逐级补入较年轻的酒；成品没有单一年份，风格长期稳定，不等于“勾兑劣酒”。
- [甜型（sweet）](sweet.md) — 甜型是葡萄酒标签中残糖最高的分级，欧盟规则下非起泡酒为 45 g/L 及以上；甜味可来自晚收、贵腐、冰酒、加强或调味液，平衡取决于酸度与酒精。
- [单宁（tannin）](tannin.md) — 单宁是一类多酚化合物，能与蛋白质结合并带来涩感；在葡萄酒中主要来自果皮、种子、果梗与橡木桶。
- [风土（terroir）](terroir.md) — 风土指一个特定地方的自然条件与人的长期实践共同作用，使农产品及其制品呈现地域特征；它不是单一土壤指标。
- [年份（vintage）](vintage.md) — 年份指葡萄采收的那一年，反映当年的天气与成熟条件；它不是酒龄或装瓶日期，无年份（NV）也不是低质的代名词。
- [整串发酵（whole bunch）](whole-bunch.md) — 整串发酵把未破碎的整串葡萄连同果梗送入发酵容器；果梗带来结构、香料与新鲜感，也会抬高 pH、带入草本味，比例取决于品种、成熟度与年份。
- [麦芽汁（wort）](wort.md) — 麦芽汁是糖化后从麦糟中分离出的含糖液体，是啤酒发酵的起点；它还不是啤酒，成分由谷物、糖化温度、过滤方式与是否加花煮沸共同决定。
