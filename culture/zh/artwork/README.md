# 艺术作品

[返回中文目录](../README.md)

- [《饮酒者》：勃鲁维尔的客栈与一张脸](brouwer-the-drinker.md) — 弗兰德斯画家阿德里安·勃鲁维尔的客栈风俗画，以莫瑞泰斯皇家美术馆藏《醉酒的农民在客栈》为代表，常被泛称为《饮酒者》。画面里酒、烟草与喧闹让所有人失去清醒；它既是滑稽的观察，也是对人性弱点的冷静注视。
- [《酒神巴克斯》：卡拉瓦乔的一杯酒与一篮水果](caravaggio-bacchus.md) — 卡拉瓦乔的《酒神巴克斯》约作于 1598 年，现藏佛罗伦萨乌菲齐美术馆。画中年轻酒神举杯朝向观者，旁边是一篮精细描绘的水果；它既像邀请，也像一幅关于醉态与古代形象的谜题。
- [《室内：饮酒女子与两位男子》：代尔夫特的一杯酒](de-hooch-woman-drinking.md) — 彼得·德·霍赫约 1658 年的室内画，现藏伦敦国家美术馆。一位女子背对观者举杯，两位男子以烟斗作乐器；画面在歌唱、饮酒与暧昧之间保持开放，红外线还显示画家删去过一个人物。
- [《韩熙载夜宴图》：一场被画下来的夜宴](han-xizai-night-banquet.md) — 传为五代南唐顾闳中所作的绢本设色长卷，纵 28.7 厘米、横 335.5 厘米，北京故宫博物院藏，一级甲文物。本文逐段读听乐、观舞、歇息、清吹、送客五幕，说明注子、温碗与杯盏如何组织夜宴节奏，并梳理宋摹本、作者归属与“窥视”叙事的争议。
- [《静物：酒杯与酒器》：海达的大酒杯与怀表](heda-still-life-drinking-vessels.md) — 荷兰画家威廉·克拉斯·海达的静物画，以莫瑞泰斯皇家美术馆藏《大酒杯与怀表》为代表。桌上的大酒杯、银器、食物与怀表被画成近乎单色的光影；它既是酒器研究，也是关于时间与节制的静物传统。
- [《兰亭集序》：曲水流觞与一篇序](lanting-ji-xu.md) — 永和九年（353）三月三日，王羲之与友人在会稽兰亭修禊、饮酒赋诗，并为诗集作序。真迹不存；北京故宫博物院藏冯承素摹“神龙本”，纸本，纵 24.5 厘米、横 69.9 厘米。本文读文本、书法与酒令，并辨“神龙”印、摹本系统与兰亭论辩。
- [《李白醉酒图》：一个被反复画的题材](li-bai-zui-jiu-tu.md) — 从上海博物馆藏苏六朋《太白醉酒图》轴（1844 年，纸本设色，204.8 × 93.9 厘米）入手，说明“李白醉酒”如何成为一个跨时代的画题，并辨析它与梁楷《李白吟行图》、波士顿美术馆《唐明皇招饮李白图卷》的区别，以及题款、断代与图像使用上的误区。
- [《清明上河图》：汴京酒肆与城市节奏](qingming-shanghe.md) — 北宋张择端绢本设色长卷，纵 24.8 厘米、横 528.7 厘米，北京故宫博物院藏，文物号新00087177。本文以孙羊店、十千脚店与虹桥一段为中心，说明正店、脚店与酒旗如何构成宋代城市的酒业网络，并梳理“清明”含义、季节与残卷诸争议。
- [《竹林七贤与荣启期》：南朝墓中的砖画](seven-sages-of-bamboo-grove.md) — 1960 年出土于南京西善桥宫山大墓的南朝模印砖画，两壁各四人；南京博物院藏本一组 78 × 242.5 厘米、一组 78 × 241.5 厘米，人物旁有姓名榜题。本文细读八人姿态、酒在名士图像中的位置，并说明墓主、年代与“顾恺之粉本”诸说。
- [《酒神的胜利》：委拉斯开兹把神话拉进人群](velazquez-triumph-of-bacchus.md) — 委拉斯开兹约 1628–1629 年的油画，现藏普拉多博物馆。酒神巴克斯与一群西班牙农民同席，举杯、加冠与饮酒把神话拉进日常；它既是对古典形象的戏仿，也是对酒神文化的重新讲述。
- [《葡萄酒杯》：维米尔的一杯酒与一扇窗](vermeer-wine-glass.md) — 维米尔约 1658–1660 年的室内画，现藏柏林国家博物馆绘画馆。一位女子坐在桌前举杯，一位男子正从酒壶中倒酒；画面把饮酒、待客与荷兰黄金时代的室内生活放在同一束窗光里。
- [《饮中八仙图》：八个人的醉态](yin-zhong-ba-xian-tu.md) — 以两件可核查的传世本为中心：台北故宫博物院旧传任仁发本与纽约大都会艺术博物馆藏明或清本；梳理杜甫《饮中八仙歌》的八人名单、诗句如何被转成人物段落，以及题款、断代与酒器解读上的常见误区。

- [《加纳的婚礼》：一面墙上的婚宴，和一场被宴席藏起来的奇迹](veronese-wedding-at-cana.md) — 委罗内塞 1562–1563 年为威尼斯圣乔治·马焦雷修道院餐厅所作的大型油画，现藏卢浮宫；画面把《约翰福音》的水变酒奇迹放进一场铺张的威尼斯婚宴，真正被放大的却是宴饮的社会秩序。
- [《苦艾酒饮者》：马奈把一个边缘人画成了历史画的大小](manet-absinthe-drinker.md) — 马奈约 1859 年的早期油画，现藏哥本哈根新嘉士伯美术馆；画面只有一个披斗篷、戴高帽的男人，脚边一只空瓶，身旁一只小杯。它被 1859 年沙龙拒绝，却成为马奈现代生活绘画的起点。
- [《苦艾酒》：德加画的是两个人坐在一起，却谁也不看谁](degas-absinthe.md) — 德加 1875–1876 年的《苦艾酒》原题《在咖啡馆》，现藏奥赛博物馆；画面里一位女演员与一位画家并排坐在巴黎咖啡馆，真正的主角不是酒，而是现代城市里的孤独。
- [《夜间咖啡馆》：凡高把一盏煤气灯画成一场通宵的发烧](van-gogh-night-cafe.md) — 凡高 1888 年 9 月在阿尔勒所作的油画，现藏耶鲁大学美术馆；红墙、绿台球桌、四盏柠檬黄煤气灯，以及几个趴在桌上的客人，构成一间不肯睡着的房间。
- [《农民婚礼》：勃鲁盖尔把一场乡村婚宴画成一张社会切片](bruegel-peasant-wedding.md) — 老彼得·勃鲁盖尔 1568 年的木板油画，现藏维也纳艺术史博物馆；新娘坐在绿布前，新郎按习俗不在席上，两个男人用卸下的门板端来麦糊，仆人把啤酒倒进壶里。
- [《文会图》：宋徽宗把一场文人饭局画成了朝廷的理想秩序](wen-hui-tu.md) — 旧传宋徽宗赵佶所作的《文会图》，绢本设色，现藏台北故宫博物院；大桌上摆着酒盏、茶具与果盘，学士围坐，仆人侍奉。它画的不是某一次真实饭局，而是北宋朝廷对文治的想象。
- [《十八学士图》：唐太宗留下的一组政治肖像，被后人画成了四种文人生活](eighteen-scholars.md) — 台北故宫收藏的一套四幅《十八学士图》，旧题宋人，今多认为明人所作；每幅以琴、棋、书、画为主题，源自唐太宗为秦王府十八学士立像的政治工程。
