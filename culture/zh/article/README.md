- [白酒香型体系：浓香、清香、酱香与米香怎么读](baijiu-aroma-systems.md) — 香型是白酒行业描述香气风格与工艺传统的一套分类语言，不是质量等级的排行榜。本文说明它从哪来、由哪些工艺与成分共同塑造，以及读标签时该看什么。
- [走出酒馆：把一杯酒追到产地](beyond-the-pub.md) — 酒馆之外还有产地。啤酒厂、蒸馏厂与酒庄的参观，把风味从“好喝”拆成原料、设备、时间与人的选择。本文说明三类参观各能看到什么、该问什么，以及哪些说法不可信。
- [酒窖与储存：温度、湿度、光照与时间](cellar-and-storage.md) — 酒窖不是把酒“放老”的魔法房间，储存的目标是让酒以可控的速度变化。本文分葡萄酒、啤酒与烈酒说明储存条件、容器差异与常见误区，并给出可执行的家庭存酒方法。
- [中国酒史纲：从谷物发酵到国家名酒](history-of-chinese-wine.md) — 以考古、农书、城市文献与近现代评酒制度为线索，梳理中国酒从早期谷物发酵、唐宋酒肆、元明蒸馏酒到近现代工业化与国家名酒的长期变化；区分证据、传说与后来的叙事。
- [酒馆史：从酒肆、客栈到酒吧](history-of-taverns.md) — 酒馆的形态由城市、交通、税收与法规共同塑造。本文以宋代正店与脚店、欧洲 inn 与 tavern、美国 saloon 与禁酒令、英国 pub 为例，说明同一功能的空间为何在不同制度下长成不同样子，并给出观察一间酒馆的四个问题。
- [酒器史：杯子如何改变喝法](history-of-vessels.md) — 酒器不只装酒，它决定温度、香气、分量与动作。本文按陶器、青铜、漆器、金银器、瓷器、玻璃六个阶段梳理中国酒器，并用建盏、爵的用途、器名错位等反例，说明器型如何反过来塑造饮用方式与礼仪。
- [世界酒史纲：从发酵饮料到全球产业](history-of-world-wine.md) — 以考古证据、法规文本与产业史料为线索，梳理葡萄酒、啤酒与蒸馏酒的三条路径，以及 19 世纪工业化、20 世纪标准与全球化如何重塑今天的酒类世界；并列起源与分期的争议。
- [黄酒史：米、曲、水与绍兴](history-of-yellow-wine.md) — 黄酒是中国谷物发酵酒的主线，从贾湖陶器残留、北魏《齐民要术》的制曲，到绍兴酒行销与 1952 年名酒评选、GB/T 13662-2018，工艺连续而品类断裂。本文说明“黄酒”作为现代分类与古代酒名之间的差别。
- [啤酒花与苦度：IBU 能说明什么，不能说明什么](hops-and-bitterness.md) — 啤酒花带来苦味、香气与保存性，IBU 是衡量异α-酸浓度的苦度单位。本文说明苦味如何产生、IBU 如何测量，以及为什么“IBU 越高越苦”并不可靠。
- [一杯酒，为什么有地方的味道？](place-and-process.md) — 产地通过气候、土壤、品种、微生物与工艺进入酒中；风土是理解产地的线索，不是质量保证。本文以葡萄酒、威士忌、白酒与黄酒为例，拆开“地方味道”的几层来源。
- [禁酒令：禁令改变供给，不消灭需求](prohibition.md) — 以美国 1920 至 1933 年的全国禁酒为主线，兼及俄国、芬兰、冰岛与中国的酒禁经验，说明禁酒法令如何执行、出现哪些漏洞、产生什么后果，以及为什么“禁酒”很少等于“无酒”。
- [认识一座城，从一间酒馆开始](pub-and-city.md) — 酒馆是城市生活的切片：营业时间、常客、酒单与座位方式，共同透露街区由谁组成、何时热闹、如何待客。本文比较 pub、咖啡馆、bar 与 beer hall 四种空间，并给出观察与阅读历史的方法。
- [清酒与烧酎：同为日本酒，工艺完全不同](sake-and-shochu.md) — 清酒是酿造酒，烧酎是蒸馏酒，二者常被中文语境混为一谈。本文从原料、发酵、蒸馏、分类与饮用方式说明它们的差别，并解释酒标上的常见术语。
- [蒸馏技术传播：从炼金术到全球烈酒](spread-of-distillation.md) — 蒸馏不是某一个人或某一个国家的发明。本文按亚历山大里亚、阿拉伯炼金术、欧洲药用蒸馏、加勒比朗姆、东亚烧酒与 19 世纪柱式蒸馏的顺序，说明技术如何在翻译、贸易与殖民中扩散，以及为什么“起源地”问题难以定论。
- [一杯酒里的时间](time-in-a-cup.md) — 从《诗经》的春酒到唐诗里的金樽，古人把节令、农事与相聚写进酒中。本文只谈文献能支持的线索，并区分文本、注本与今天的想象。
- [酒与节庆：节令酒里的时间表](wine-and-festivals.md) — 中国传统节令几乎都配一种酒：岁首的屠苏、端午的雄黄、中秋的桂花、重阳的菊花。本文按节令梳理这些酒的原料、文献来源与民俗含义，并说明哪些做法今天已不适合饮用。
- [酒与画：宴饮图像的四种看法](wine-and-painting.md) — 酒在绘画里很少只是静物：它标出身份、时间与人与人的关系。本文以《清明上河图》《韩熙载夜宴图》、卡拉瓦乔《巴克斯》与荷兰风俗画为例，提出“器物—空间—关系—叙事”四层读法，同时说明图像证据的边界。
- [酒与诗：从《诗经》到宋词的饮酒书写](wine-and-poetry.md) — 酒在中国诗里既是宴饮道具，也是时间、友情与政治处境的标记。本文按先秦、魏晋、唐、宋四段梳理饮酒诗的变化，说明不同时代的酒器、酒令与写作动机，并给出把诗当史料时的边界。
- [酒与礼：从乡饮酒礼到今天的敬酒](wine-and-ritual.md) — 酒在中国礼制里承担次序与身份的功能。本文从《周礼》的酒官与五齐三酒、《仪礼》的乡饮酒礼、《礼记》的玄酒与《士昏礼》的合卺讲起，说明酒器、座次与敬酒如何把关系写成动作，并区分经典规范、后世实践与当代劝酒。
- [葡萄酒分级体系：地理标志、国家等级与酒庄分级](wine-grading-systems.md) — 酒标上的 AOC、AOP、IGP、DOCG 等缩写常被混为一谈。本文把“分级”拆成地理标志保护、国家质量等级与酒庄或地块分级三个层面，并说明它们能证明什么、不能证明什么。
