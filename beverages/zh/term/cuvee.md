# 调配（cuvée）

cuvée 是一个被过度使用的法语词。它至少有两层工艺含义：起泡酒压榨时最先流出的轻柔汁液，以及由多个基酒组合成的一批酒。到了酒标上，它又常常只是产品名。三层含义互相交叠，但没有任何一层等于法定质量等级。

## 定义与边界

在压榨语境中，cuvée 指第一段、低压力下流出的汁液；在调配语境中，它指已经组合好的一罐或一批酒。两者都强调“从容器里取出的一组酒”，但前者按压榨顺序定义，后者按批次完整性定义。cuvée 不是分级术语，也不是年份术语；它不保证酒液更老、更好或更贵。理解这个词，必须先判断它出现在工艺描述、酒庄内部记录还是酒标营销中。cuvée 可以指一个单一批次，也可以指多个批次组合后的整体；因此它既能描述“这一罐”，也能描述“这一款”。

## 词源与来源

cuvée 来自法语 cuve（发酵槽、大桶），而 cuve 又源自拉丁语 cupa（桶、容器）。字面意思是“装在槽里的一批酒”。在香槟，压榨分馏把 cuvée 与 taille 区分开；在酒庄内部，cuvée 指已调配好的一罐或一批；在市场上，它被用作产品名，含义由生产者定义。在香槟法规语境，cuvée 与 taille 的分馏受压榨规范约束；在其他产区，cuvée 并没有统一的法定定义，更多是行业习惯。词源本身不含有“顶级”的意思，这一点常被营销叙事忽略。同源的 cuverie 指发酵车间，cuvaison 指浸渍发酵阶段；它们共享“在槽中处理”的核心，而 cuvée 只是其中被取出或组合的那一批。

## 机制与参数

香槟的压榨单位称 marc，传统上为 4,000 公斤葡萄。按现行规则，最先流出的 2,050 升称 cuvée，随后 500 升称 taille，总计 2,550 升。cuvée 取自较低压力，颜色更浅、口感更细；taille 压力更高，带更多色素与单宁。压榨机类型、装料量、压力曲线与分段时间都会影响分馏结果。传统篮式压榨与气膜压榨对果皮的压力不同，取出的 cuvée 在颜色、悬浮物与口感上也会有差异；分馏通常持续数小时，前段与后段的温度、氧化程度并不相同。调配阶段，不同地块、品种与年份的基酒按比例组合，形成最终的 cuvée，因此“cuvée”也可以是一个动词化的工艺结果。

## 在酒业中的实际用法

在香槟，cuvée 与 taille 可以分开发酵、分开调配；是否使用 taille、使用多少，取决于酒庄风格与法规。无年份香槟通常调入不同年份的储备酒，单一年份香槟则只用一个采收年；前者依靠储备酒维持风格，后者强调该年的气候特征。无论哪种，cuvée 都是调配决策的结果，而不是某个固定等级的代名词。Prestige cuvée（顶级特酿）是市场用语，常见例子包括 Dom Pérignon、Cristal 与 Krug Grande Cuvée；它不是法定等级，也不自动对应更长时间陈年。静止酒也会用 cuvée 作为产品名，但它与起泡酒的压榨分馏没有必然关系。

## 易混术语对照

第一组：cuvée 与 blend。[混酿](ref:blend)是通用的“把不同酒液组合”概念；cuvée 更常用于起泡酒或酒庄产品名，且在香槟还可指压榨的第一段汁液。第二组：cuvée 与 taille。二者是同一压榨过程的两段，不是质量等级；cuvée 通常更轻柔，taille 更重。第三组：cuvée 与 vintage。cuvée 可以是无年份，也可以是单一年份；名称本身不告诉你年份。第四组：cuvée 与 cru。cru 指地块或分级意义上的“生长地”，cuvée 指一批酒；一个 cru 可以产出多个 cuvée，一个 cuvée 也可以跨多个 cru。

## 常见误用与争议

第一，把 cuvée 当作“最高等级”；它不是分级。第二，把 cuvée 一律当作“第一次压榨汁”；在酒标上它常常只是产品名。第三，把 prestige cuvée 当作法定术语；它是行业与市场称呼，使用门槛由生产者与品牌决定。第四，认为 cuvée 必须是混酿；单一品种、单一年份也可以叫 cuvée。争议在于标签自由度：同一词在不同产区的约束不同，消费者很难只凭词判断工艺，只能继续查看生产者与产区信息。还有一个误用，是把 cuvée 等同于高价；价格由品牌、年份、陈年与稀缺性共同决定，词本身不背书。另一个混淆，是把 tête de cuvée 与 prestige cuvée 当作同义；前者更强调“头等”，后者更强调市场定位，两者都不是法定等级。

cuvée 在香槟、葡萄酒与烈酒里并不完全同义；它常指一批调配或特定酒款，而不是一个法定质量等级，看到这个词不能直接推断品质。

## 典型数值与例子

香槟压榨的常见参数是：1 marc 等于 4,000 公斤葡萄，cuvée 为 2,050 升，taille 为 500 升，总取汁上限为 2,550 升；cuvée 约占总取汁的 80%，taille 约占 20%。以 Dom Pérignon 为例，它是 Moët & Chandon 的 prestige cuvée，通常为单一年份；Krug Grande Cuvée 则是多年份调配。两者都叫 cuvée，但年份结构与法规身份完全不同，说明这个词不能单独承担质量判断。

## 记录与表达

记录 cuvée 时，先问它是“压榨段”还是“调配批次”，再问是单一年份还是多年份、是否混品种、是否经过苹乳发酵。酒标上若只写 cuvée，应把它当作产品名，继续查找生产者、产区与年份信息；如果是香槟，还可以结合 blanc de blancs、blanc de noirs 等标注推断品种结构。选购时，把 prestige cuvée 当作风格与定位线索，而不是法定等级；价格与陈年时间仍要单独核对，别让一个词替代了酒标阅读。如果同一酒庄有多款 cuvée，应记录各自基酒比例与年份结构，而不是只记名称。
