# 酒器

[返回中文目录](../README.md)

- [苦艾酒杯](absinthe-glass.md) — 杯腹宽、杯口收的玻璃杯，常配雕花糖匙；用于苦艾酒的“加水稀释”仪式，让酒液从翠绿变为乳白。
- [啤酒马克杯](beer-mug.md) — 带把手、杯壁较厚的大容量啤酒杯，常见于德国啤酒文化；厚壁保冷，把手隔热，宽口便于大口饮用。
- [香槟笛杯](champagne-flute.md) — 杯身细长、杯口略收的带梗杯，常用于香槟与气泡酒；窄杯身有利于保持气泡，但香气展开较弱。
- [雪莉小杯](copita.md) — 西班牙雪莉品鉴用的小型带梗郁金香杯，杯腹收拢、杯口略外扩，常见容量约 100–150 ml；也用于部分烈酒的闻香品鉴。
- [碟形杯](coupe-glass.md) — 带杯梗的浅碗形杯，常用于香槟、气泡酒与滤冰后直接饮用的短饮；杯口宽、杯身浅，香气开放但气泡消散较快。
- [醒酒器](decanter.md) — 用于分离沉淀、让酒液接触空气的玻璃容器，常见宽底、长颈、带塞；醒酒时间要看酒龄、酒体与香气。
- [高脚广口杯](goblet.md) — 带梗、杯腹宽、杯口开放的杯型，常用于比利时修道院啤酒、部分葡萄酒与餐桌水；容量常见 250–500 毫升，以具体产品为准。
- [高球杯](highball.md) — 直身、细长、容量较大的长饮杯，常用于加冰长饮与气泡类鸡尾酒；容量没有统一标准，冰量与苏打水应按自己的杯子调整。
- [飓风杯](hurricane-glass.md) — 杯身细长、中部鼓起、杯口外翻的高杯，形似老式飓风灯罩；常用于热带鸡尾酒与大量碎冰的饮品。
- [朱利普杯](julep-cup.md) — 银制或锡制的小型金属杯，常用于薄荷朱利普；金属导热快，杯壁会结霜，碎冰与薄荷让酒液保持低温。
- [马天尼杯](martini-glass.md) — 锥形、有梗、杯口略收的短饮杯，也常称鸡尾酒杯，用于干马天尼、玛格丽特与代基里等短饮；容量没有统一标准，预冷比杯型更影响体验。
- [尼克与诺拉杯](nick-and-nora.md) — 名字来自 1934 年电影《瘦人》里的一对侦探夫妻；浅碗、宽口、细梗的小型带梗杯，常见容量约 150–200 ml，适合不加冰的短饮。
- [品脱杯](pint-glass.md) — 英国 568 毫升、美国 473 毫升的直身啤酒杯；锥形、nonic 与带柄 jug 是常见形制，容量随国家与产品而变。
- [红酒杯](red-wine-glass.md) — 杯身宽大、杯口略收的带梗酒杯，用于红葡萄酒；较大的杯腹帮助香气展开，收口则让香气集中于杯口。
- [古典杯](rocks-glass.md) — 杯身较矮、杯口较宽的短饮杯，常用于加冰纯饮与搅拌类鸡尾酒；容量没有统一标准，冰量应按自己的杯子调整。
- [烈酒杯](shot-glass.md) — 容量很小、杯壁较厚的小杯，常用于一口饮用的烈酒、量酒与分层鸡尾酒；它追求的是方便与强度，不是香气层次。
- [白兰地杯](snifter.md) — 短梗、大肚、收口的杯型，传统用于干邑与白兰地；常见容量 300–800 ml，但实际倒酒量远小于容量。
- [品鉴杯](tasting-glass.md) — 以 ISO 3591 标准品鉴杯（常称 INAO 杯）为代表的郁金香形小杯，标准容量 215 毫升，用于葡萄酒、烈酒与清酒的对照品评。
- [Tiki 杯](tiki-mug.md) — 以陶瓷或玻璃制成的异形杯，常雕刻成提基神像、面具或图腾；它是热带鸡尾酒文化的一部分，容量与造型都比普通杯更夸张。
- [郁金香杯](tulip-glass.md) — 杯腹较宽、杯口收窄的带梗杯，常用于香槟、啤酒与部分短饮；在香气聚集与气泡保持之间取得折中。
- [威士忌闻香杯](whisky-nosing-glass.md) — 杯腹呈郁金香形、杯口收窄的小型品鉴杯，用于威士忌闻香与少量品饮；收口聚香，短底座便于掌心托杯。
- [白葡萄酒杯](white-wine-glass.md) — 杯腹较小、杯口收窄的带梗酒杯，用于白葡萄酒；较小的杯腹限制氧化，收口保留花香与酸度，适合低温饮用。
